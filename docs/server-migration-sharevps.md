# sharevps新站归一化

本次为已授权的全新空站部署，取代之前保留旧数据与旧域名代理的迁移方式。唯一控制主机为`107.151.244.106`，使用新域名的用户、管理和API三个入口。

- 不导入旧用户、订阅、订单、服务器、节点、支付、人机验证、业务DNS或其密钥；旧数据只留受限归档。
- 不保留旧域名代理、支付回调、订阅URL兼容；客户端只使用新的官方入口。
- PostgreSQL 18＋Redis 8为新正式存储，网站HTTPS证书保留，业务设置由管理员重新配置。
- 先独立准备并验证新环境，再退役旧节点、停止旧控制、保存最终归档，最后切换正式目录。新站验收后清除旧主机的HQIP专属文件和授权，不影响其他项目。
- 后续自动发布只替换完整可验证代码产物，保留新站数据库及用户配置，不再依赖旧机或旧发布文件。

实际命令、最终备份回执及验收要求见[全新空站部署](fresh-deployment.md)。之前的历史迁移和空站替换脚本不用于日常上线。
