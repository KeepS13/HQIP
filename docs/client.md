# Windows 客户端使用说明

HQIP 客户端使用独立设备账号登录，自动同步管理员分配的节点和规则。Windows x64 发布包包含 `HQIP.exe`、固定版本 sing-box 1.14.4、`hqip-helper.exe`、依赖文件、校验清单及第三方许可。请完整解压到固定目录后运行 `HQIP.exe`，不要只复制主程序。界面需要 Microsoft Edge WebView2 Runtime。

## 准备设备账号

1. 在管理电脑打开 `http://127.0.0.1:8080`，进入“设备”，创建一台设备记录。
2. 在设备详情“节点分配”中勾选允许使用的节点，并选择其中一个作为默认节点。新设备没有自动分配节点；新增服务器也不会自动加入已有设备。
3. 在“客户端账号”中设置用户名，密码留空可生成随机密码。用户名为 3–64 位英文字母、数字或 `_.@-`，首位须为字母或数字；自设密码至少 12 位。
4. 保存页面一次性显示的服务地址、用户名和密码。关闭窗口后不能再次读取密码，可重置生成新密码；重置会使该设备的全部桌面登录会话失效。

桌面登录使用设备账号；管理员账号用于管理网站。客户端服务地址使用公网 HTTPS 地址，例如 `https://testvps.sharevps.online`，不会因为管理员页面位于本机而改成 `127.0.0.1`。同一设备账号登录多台电脑会共享设备身份，建议每台电脑分别登记。

## 连接和路由

首次登录后选择节点，再点击“连接”。客户端先检查配置并完成真实代理访问和出口验证，成功后才显示“已连接”。节点必须已完成部署、外部验证与设备授权同步。Hysteria 2 需要当前网络支持 UDP，TLS 验证始终开启。

- **规则模式**：按控制面下发的有序规则选择直连、代理或拒绝。由本次原 Clash 配置导入的 1709 条规则保留顺序；Bilibili、Linkedin、Steam、Epic、Apple 的服务策略为直连，其余服务策略使用当前节点。未命中规则的请求使用当前节点。
- **全局模式**：普通请求使用当前节点。局域网、控制服务、节点连接和维持隧道所需进程仍保留必要直连，以免代理自身形成循环。
- **系统代理**：默认模式，支持系统代理的应用可使用 HQIP。
- **TUN**：覆盖更多应用流量。首次启用需要接受 Windows UAC 提权，安装受限的 `HQIPHelper` 服务。请先关闭其他客户端的 TUN，避免路由冲突。

HQIP 不修改现有 Clash 订阅文件。切换系统代理时会保存自身接管的设置，断开或退出时恢复仍由 HQIP 持有的设置；若其他软件已修改相关值，则保留其他软件的新设置。需要切回 Clash 时，先在 HQIP 中断开，再启用 Clash 的系统代理或 TUN。

点击窗口右上角关闭按钮会隐藏到托盘，连接继续运行。托盘可重新打开、连接、断开，或选择“退出并恢复网络”。手动断开后，配置同步不会自动重新连接；程序重新启动后也等待手动连接。

## 配置变化与状态

客户端通常每 5 秒同步一次；失败时逐步退避，最长 60 秒。连接期间管理员调整默认节点、可用节点或规则时，客户端会尝试应用新配置。手动选择可切换到同一设备的其他已分配节点。

管理网站分别展示目标节点、实际节点和三种版本：

| 字段 | 含义 |
| --- | --- |
| 期望版本 | 控制面要求设备处理的配置 |
| 已处理版本 | 客户端已处理该配置，可能成功、断开或失败 |
| 已应用版本 | 最近一次成功运行的配置 |
| 实际节点 | 当前验证成功且仍在运行的连接节点 |

配置校验或新节点连接失败时会停止代理、清空实际节点并显示错误，不会把目标节点显示为已连接。控制面暂时离线时，已运行的连接可继续使用最后成功配置；新授权、账号登录、订阅下载和撤销同步需要控制面恢复。客户端心跳超过 30 秒后，管理页面将状态视为过期。

移除节点分配会先通知客户端处理新配置，再由节点 Agent 撤销凭据。宽限期从 Agent 实际收到移除任务开始计算；节点离线时保持待同步，不能仅因倒计时结束就视为完成。设备停用和订阅轮换采用立即撤销流程，也必须等节点确认。重新分配节点会生成新连接凭据。

网站的“在线登记设备”按设备身份跨节点去重，“客户端连接实例”统计代理连接；桌面登录会话单独展示。这些数值均不代表已识别真实物理硬件。代理流量按北京时间自然月累计上传与下载，与服务商账单口径不同；额度只提醒，不主动限速或断网。

## 本机数据与排查

客户端数据位于 `%LOCALAPPDATA%\HQIP\Client`。会话令牌和缓存节点配置由当前 Windows 用户的 DPAPI 加密保存，不能直接拷贝给另一用户使用。TUN 服务安装在 `%ProgramFiles%\HQIP Helper`，通过仅授权用户可访问的命名管道接收受限配置，内核文件须与固定 SHA-256 一致。

- **登录失败**：确认使用设备账号、公网 HTTPS 服务地址，且本地控制面与反向 SSH 隧道正在运行；账号重置或设备停用后需要重新登录。
- **没有可连接节点**：检查该设备的节点分配、节点就绪状态，以及 Agent 的授权同步。
- **连接失败**：查看客户端最近错误，核对 UDP 网络、节点证书和出口验证。不要关闭证书验证。
- **TUN 启用失败**：检查 UAC 是否允许、是否有其他 TUN 正在运行，以及 Windows 服务 `HQIPHelper` 的状态。
- **网络恢复**：优先在托盘选择“退出并恢复网络”；程序异常退出由本机监护进程尝试恢复代理，下一次启动也会检查遗留代理租约。

## 管理员维护规则

规则导入器只读取有序路由规则及已核对的服务组默认值，不导入原来的节点、订阅 URL 或连接密码。当前导入器针对这份 1709 条规则的配置；输入的服务组或默认值变化时会报错，需审查后再调整导入逻辑。

```powershell
python scripts/import_clash_rules.py --input 'C:\path\to\clash-verge.yaml' --output .local/rules/bundle.json --sing-box dist/desktop/sing-box.exe
```

CN 地址使用 `gaoyifan/china-operator-ip` 的固定提交 `ffabdf398bf6c9b3ffa2d66e536155b87188d0d9`，许可为 MIT。生成目录保留数据摘要、上游来源和许可副本；原始用户规则及运行规则包不提交代码仓库。管理员通过 `PUT /api/v1/rules` 提交 `{ "bundle": ... }`，控制面规范化、校验、生成版本和 SHA-256；客户端下载后校验原始响应字节的摘要，再生成本地 sing-box 规则集。接口详见 [接口约定](interfaces.md)。
