# HQIP Windows 4.5.0 客户端

用户入口为 [hqip.sharevps.online](https://hqip.sharevps.online)，管理入口为 [cms-hqip.sharevps.online](https://cms-hqip.sharevps.online)。客户端连接 API `https://api-hqip.sharevps.online`，使用邮箱账户通过系统浏览器完成 PKCE 授权；客户端不保存账户密码，DPAPI 保护令牌和连接配置。用户网页注册、改密及管理员重置密码均至少 6 个 Unicode 字符、最多 1024 字节。注册、网页登录仍需要 Turnstile。

## 订阅与连接

每个用户可以同时持有多份独立流量包。客户端登录后首次使用时手动选择订阅，再选择订阅允许的节点；连接由用户手动开启。选择保存在本机安装实例，另一台设备的选择不会被改变。以后再次选中同一份订阅时恢复本机上次选择的节点；首次选择或节点已被移出授权集合时，使用服务端自动候选：在线人数最少，其次服务器剩余流量最多，再次服务器最早到期。当前节点仍获授权时不因排名变化切换。

订阅带宽、一次性总流量、到期时间和并发 VPN 连接数分别执行。客户端会显示当前实例已用量、待结算预留、期限和连接占用；同一实例供多台设备使用时共享其限制。账户登录不占 VPN 名额，等待服务端确认关闭的代理连接仍占名额。

首次连接默认规则模式和系统代理。全局模式仍保留访问本地网络和控制服务所需的直连路径。TUN 会请求 Windows UAC 授权，并使用最小权限辅助服务。HQIP 只恢复仍由自身持有的系统代理、路由或 DNS 设置，不覆盖其他应用后来修改的值。

切换节点或订阅会先停止旧连接，等待关闭确认，再获取新凭据并连接；即使连接到同一节点，更换订阅也会重新鉴权以保证计量归属。快速切换只应用最新选择，手动断开优先于正在执行的切换。代理关闭时更改选择只保存，不会自动连接；单纯用量刷新不触发重连。

如果当前订阅到期、耗尽、停用或被移除，客户端停止 VPN、恢复 HQIP 网络设置并显示原因。当前节点被移出同一有效订阅时，服务端提供合格候选，客户端自动停止旧连接并切换；断开状态只更新选择。没有候选时显示“暂无可用节点”并停止，用户可稍后刷新或手动选择。不会跨订阅回退。

## 仪表盘

客户端仪表盘显示实时上下行、近 60 秒速率曲线、本次连接流量和时长、当前订阅剩余量与期限、连接占用、当前节点、规则／全局模式及系统代理／TUN 状态。内核指标每秒采样，订阅与服务器状态每 5 秒同步；指标采样失败保留累计流量和连接时长，实时速率清零并标记过期。界面分别标明本机采样流量和服务端确认计费流量，两者不可互相推算。手动延迟测试只针对当前连接节点，测试流量计入当前订阅。

本地网络、API 管理连接和节点连接绕过代理与 TUN，避免断开 VPN 后无法刷新。成功连接后，客户端自动在后台维护同一节点的连接与授权，数据仍可传输时显示绿色“已连接”；实际链路中断时显示“恢复中”，用户仍可随时手动断开。首次连接失败仍提示，订阅到期、额度耗尽、撤权、证书或本地内核错误仍停止并提示。旧单套餐客户端接口返回升级提示，需安装 4.0 或更新版本。

## 安装、账户与支持

从用户端客户端下载 Windows x64 包并核对 SHA-256，将 ZIP 解压至固定目录，保留客户端、辅助程序、sing-box 和相关 DLL。首次启动 Edge WebView2 Runtime 必须可用。首次登录会打开浏览器，完成用户授权后返回客户端。浏览器的“账户设置”链接始终打开用户域名。

客户端、登录页、侧栏、程序图标和托盘统一使用紫色 H 品牌。关闭窗口会隐藏至托盘；断开连接或退出时客户端会恢复 HQIP 管理的网络设置。若连接、TUN 或恢复失败，请检查 Windows 辅助服务状态、UAC 授权以及其他代理软件是否占用了相同设置。

“连接设置 → 开机自启”默认关闭，未登录 HQIP 账户也可调整。开启后，当前 Windows 用户登录时自动打开客户端，VPN 仍需手动连接；关闭开关会移除 HQIP 的启动项。设置对当前 Windows 用户生效，不需要管理员授权，退出 HQIP 账户不会清除该设置。客户端应保留在固定目录；移动目录或将新版解压到另一目录后，请在新版中关闭再重新开启，以更新启动路径。如果在 Windows“启动应用”或任务管理器中禁用了 HQIP，还需在那里重新启用。

客户端使用带状态标记的新 H 图标：紫灰减号表示未连接，蓝色省略号表示连接或切换中，绿色对勾表示已连接，红色感叹号表示连接失败。账户接口暂时失败但节点仍可转发时保持绿色已连接；节点链路恢复期间显示黄色“恢复中”。运行时任务栏、托盘和客户端侧栏随 VPN 状态更新；隐藏到托盘后仍会更新，鼠标悬停托盘可查看文字状态。桌面快捷方式、资源管理器及未运行时固定的任务栏图标使用默认紫色图标。

4.1 增加托盘订阅、节点、规则／全局和 TUN 操作，以及侧栏迷你流量图。选择菜单支持键盘操作。浏览器授权回调页只表示授权码已送达，请返回客户端确认登录结果；不会把尚未完成的令牌交换显示为登录成功。

4.2 增加无边框窗口和手动节点网络延迟列表，选择菜单与托盘只列出有效订阅。节点网络测试测量 QUIC/TLS 握手，不发送代理鉴权，不代表实际代理可用性；当前已连接节点的 HTTPS 延迟测试仍会使用订阅流量。

4.3.3 修复单一出口验证服务超时导致节点被误判不可用的问题。连接时先通过当前节点访问 Cloudflare；验证服务暂时失败时，仍通过同一节点使用 IPify 复核，整个验证最多 25 秒。两次都必须通过 HTTPS 证书校验，出口 IP 必须匹配所选节点；出口不匹配或手动取消时立即停止。不会切换到其他节点，也不会改用直连绕过检查。验证请求产生的少量流量计入当前订阅。

4.3.4 统一使用当前官方站点。旧服务地址不再自动迁移，也不再享有官方站点之间的跨域授权或额外直连规则；已保存旧地址的用户可在登录页展开“服务地址”，点击“恢复默认地址”后重新登录，也可手动填写自建服务的 HTTPS 根地址。地址在登录成功后保存，等待浏览器授权时不能修改；自建服务仍使用配置的地址和同源授权。客户端发现新版本会弹窗提醒，允许稍后更新，当前连接继续保持。

4.3.5 使用服务端自动选点结果，优先在线人数最少、服务器剩余流量最多、最早到期的合格节点。原节点仍在订阅内时保持选择；连接中原节点被移出同一有效订阅时自动切换，手动断开后只更新选择。没有合格候选时提示“暂无可用节点”，不会跨订阅选择。更新提醒仍允许稍后处理，提示本身不会中断当前连接。

4.3.6 在服务端确认登录会话失效或账户授权被撤销后，自动退出账户、清除本机登录凭据和订阅缓存、停止 VPN，并展示登录页。访问令牌正常续期不会退出；网络超时、限流或服务端暂时异常也不会清除登录状态。旧会话的延迟响应不会影响重新登录后的会话。

4.4.0 增加当前 Windows 用户的开机自启开关，默认关闭，未登录 HQIP 账户也能调整。重新设计 H 图标，任务栏、托盘和侧栏随 VPN 状态切换；开机启动客户端后仍由用户手动开启 VPN。

4.4.1 优化账户同步与更新检查的 IPv4／IPv6 地址选择，以完成 HTTPS 证书校验的连接为准，再发送一次 HTTP 请求。

4.4.2 统一客户端的已连接展示，后台连接维护期间主面板、侧栏、任务栏及托盘持续保持绿色“已连接”。

第三方客户端在用户端侧边栏的“订阅导入导出”中管理，订阅详情可直接跳转并选中当前订阅。支持 Clash/Mihomo、Clash Verge、Clash Meta Android、v2rayN、v2rayNG、Shadowrocket 和 Sing Box，可复制链接或下载对应配置；客户端操作说明见[用户门户](portal.md)。链接只控制该订阅的第三方导入入口；轮换或撤销不会删除订阅实例，也不会影响 HQIP 客户端的独立连接凭据。

## 控制服务暂不可达

4.5.0 支持节点离线许可。此前已成功授权并连接的订阅，可在原节点继续传输和手动重连，包括客户端重启后；首次登录、切换节点或订阅仍需要控制服务。

许可从节点最后一次成功核验授权起最长 24 小时，订阅到期时间更早时按订阅截止。重连、重启和失败的刷新不会延长许可。节点先使用预留的套餐流量，用尽后仅在控制服务失联时使用应急流量；每份订阅有效期内所有节点合计最多 1 GiB，不额外扣款，不因网络恢复而重置。许可到期、明确撤权或可用预算耗尽会停止转发。控制服务失联期间新发生的撤权，最迟在恢复核验或原许可到期时生效。

账户用量显示最后同步时间，应急流量单独统计。手动断开和退出登录立即生效，不会被后台恢复任务重新连上。未启用该能力的旧节点保留原有短期授权策略。
