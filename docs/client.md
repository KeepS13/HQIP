# HQIP Windows 3.0 客户端

HQIP 使用邮箱账号登录。网页登录、客户端登录和 VPN 连接是不同状态：登录不占用套餐连接名额，实际代理连接才占用名额。网页版入口为 https://hqip.5202345.xyz，管理员入口为 `/admin`。

## 安装与登录

1. 在网站注册邮箱和密码，完成 Cloudflare 人机验证。邮箱作为账号使用，首版不验证邮箱归属；忘记密码请联系管理员重置。
2. 注册后没有套餐，需管理员开通并设置到期日。网站总览可查看套餐和允许的节点。
3. 从网站“订阅与下载”下载 Windows x64 包，核对页面 SHA-256，将整个 ZIP 解压到固定目录。请保留 `HQIP.exe`、`hqip-helper.exe`、`sing-box.exe`、`libcronet.dll` 等配套文件。界面需要 Microsoft Edge WebView2 Runtime。
4. 先在旧客户端托盘选择“退出并恢复网络”，再启动新包。旧设备账号不再有效；不用删除旧用户数据目录，新版会忽略旧设备令牌。
5. 服务地址使用 `https://hqip.5202345.xyz`，点击“在浏览器中登录 / 注册”。系统浏览器完成登录和授权后会返回本机回调，客户端自动取得账号和节点。不要把管理员账号用于客户端。

客户端不保存密码；只用当前 Windows 用户的 DPAPI 保护令牌和必要连接配置。回调使用一次性授权码、PKCE 和 state。不能将缓存文件拷贝给另一 Windows 用户。

网站、登录页、客户端侧栏、Windows 程序和托盘统一使用紫色 H 标志。关闭窗口会隐藏到托盘，只有“断开”或“退出并恢复网络”才会停止连接。

## 连接与套餐限制

首次使用默认“规则模式 + 系统代理”，由用户手动开启连接。客户端校验配置、证书和真实代理访问后才显示已连接。

- **规则模式**保留现有有序分流规则及 Apple、Steam、Epic、LinkedIn、Bilibili 的默认直连。未命中规则的普通请求使用所选节点。
- **全局模式**将普通请求送至所选节点；局域网、控制服务、节点连接等必要连接仍直连，避免代理循环。
- **系统代理**适合遵循 Windows 代理设置的应用。HQIP 只恢复仍由自身持有的设置，不覆盖其他软件后来修改的值。
- **TUN**覆盖更多应用，首次使用需 UAC 授权安装受限辅助服务。请先关闭其他软件的 TUN；HQIP 不会自动结束 Clash。

套餐带宽由同一用户在所有节点上的连接共享，上传、下载分别执行同一 Mbps 上限。流量为本次开通有效期内上传加下载的一次性总额，不按月清零；客户端验证和测速也消耗套餐流量。服务器、节点的月流量只用于管理员监控，与用户套餐额度独立。

“在线连接数”按 VPN 连接计数，不是识别出的物理设备数。复制订阅或同时使用多种客户端会占用更多名额。名额用尽时显示“在线连接数已达套餐上限”，已存在的连接继续使用。可在网站“在线连接”断开自己的连接；释放名额需等待节点确认，不能只凭客户端退出就马上重发。

流量用尽、到期或停用会停止连接。未结算预算显示为“待结算”，不会被当作可重新发放的剩余流量。改套餐或延长到期时间保留已用量；只有管理员明确结束当前套餐并重新开通才开始新额度。

## 自动同步和切换

通常每 5 秒查询配置，失败时退避。当前节点仍在套餐中时保留用户选择；当前节点被移除时改用默认节点。切换先断开旧连接，等待服务器确认释放，再尝试新节点。

默认节点不可用时停止 VPN、恢复 HQIP 接管的网络设置、关闭连接开关并显示失败，不退回旧节点，也不自动选择别的节点。代理关闭时的更新只保存，不会自动连接。手动断开优先于正在执行的更新。

控制服务失联时不批准新连接；已有连接最长继续 120 秒，节点租约或套餐到期可以更早停止。控制服务恢复后需手动重连。节点自身失联也可能让名额和预算暂处于待确认状态。

## 第三方订阅

网站允许创建、轮换或撤销自己的订阅链接；链接含访问凭据，请勿分享。完整 Mihomo 配置保留路由规则，直接连接节点 IP，以节点域名作 SNI 并验证 TLS。默认使用手选节点，关闭自动测速，避免后台测试占名额。

第三方连接执行同样的服务端带宽、并发、流量、期限限制。但自动刷新、节点切换、提示和系统代理恢复由第三方软件负责，不能保证与 HQIP 客户端相同。

## 常见问题

- **人机验证未配置/不可用**：新用户注册、登录会被阻止；管理员可通过 `/admin` 修复 Turnstile。无需关闭证书验证。
- **已登录但没有节点**：等待管理员开通套餐，或检查套餐期限及节点授权。
- **在线连接数已达上限**：先在网页查看现有连接，断开不需要的连接并等待节点确认。网页或客户端登录本身不占名额。
- **连接失败**：检查当前网络是否支持 UDP、节点证书和套餐状态。管理员移除了所选节点时，应先检查新默认节点。
- **TUN 失败**：检查是否取消 UAC、其他 TUN 是否正在运行以及 Windows `HQIPHelper` 服务状态。
- **网络恢复**：在托盘选择“退出并恢复网络”；异常退出时监护进程会尝试恢复设置，下次启动也检查遗留代理租约。

客户端数据位于 `%LOCALAPPDATA%\HQIP\Client`。辅助服务位于 `%ProgramFiles%\HQIP Helper`。发布包 `manifest.json` 标明源码提交、固定 sing-box 1.14.4 / Wails v3.1.0、各二进制摘要及图标摘要，第三方许可见 `THIRD-PARTY-NOTICES.txt`。
