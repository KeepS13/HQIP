# HQIP Windows 4.0 客户端

用户入口为 [hqip.5202345.xyz](https://hqip.5202345.xyz)，管理入口为 [cms-hqip.5202345.xyz](https://cms-hqip.5202345.xyz)。客户端连接 API `https://api-hqip.5202345.xyz`，使用邮箱账户通过系统浏览器完成 PKCE 授权；客户端不保存账户密码，DPAPI 保护令牌和连接配置。用户网页注册、改密及管理员重置密码均至少 6 个 Unicode 字符、最多 1024 字节。注册、网页登录仍需要 Turnstile。

## 订阅与连接

每个用户可以同时持有多份独立流量包。客户端登录后首次使用时手动选择订阅，再选择订阅允许的节点；连接由用户手动开启。选择保存在本机安装实例，另一台设备的选择不会被改变。以后再次选中同一份订阅时恢复本机上次选择的节点；若节点已被移出授权集合，则采用该份订阅的默认节点。

订阅带宽、一次性总流量、到期时间和并发 VPN 连接数分别执行。客户端会显示当前实例已用量、待结算预留、期限和连接占用；同一实例供多台设备使用时共享其限制。账户登录不占 VPN 名额，等待服务端确认关闭的代理连接仍占名额。

首次连接默认规则模式和系统代理。全局模式仍保留访问本地网络和控制服务所需的直连路径。TUN 会请求 Windows UAC 授权，并使用最小权限辅助服务。HQIP 只恢复仍由自身持有的系统代理、路由或 DNS 设置，不覆盖其他应用后来修改的值。

切换节点或订阅会先停止旧连接，等待关闭确认，再获取新凭据并连接；即使连接到同一节点，更换订阅也会重新鉴权以保证计量归属。快速切换只应用最新选择，手动断开优先于正在执行的切换。代理关闭时更改选择只保存，不会自动连接；单纯用量刷新不触发重连。

如果当前订阅到期、耗尽、停用或被移除，客户端停止 VPN、恢复 HQIP 网络设置并显示原因。目标订阅或默认节点不可用时，不回退旧配置、不自动选择其他订阅或节点。用户需要在仍有效的订阅中手动选择并重新连接。

## 仪表盘

客户端仪表盘显示实时上下行、近 60 秒速率曲线、本次连接流量和时长、当前订阅剩余量与期限、连接占用、当前节点、规则／全局模式及系统代理／TUN 状态。内核指标每秒采样，订阅与服务器状态每 5 秒同步；刷新失败保留最近数值并标注过期。界面分别标明本机采样流量和服务端确认计费流量，两者不可互相推算。手动延迟测试只针对当前连接节点，测试流量计入当前订阅。

本地网络、API 管理连接和节点连接绕过代理与 TUN，避免断开 VPN 后无法刷新。控制服务失联时节点不会批准新连接，已建立连接最多在本地继续 120 秒后停止转发。控制恢复后用户可手动重连。旧单套餐客户端接口返回升级提示，需安装 4.0 或更新版本。

## 安装、账户与支持

从用户端客户端下载 Windows x64 包并核对 SHA-256，将 ZIP 解压至固定目录，保留客户端、辅助程序、sing-box 和相关 DLL。首次启动 Edge WebView2 Runtime 必须可用。首次登录会打开浏览器，完成用户授权后返回客户端。浏览器的“账户设置”链接始终打开用户域名。

客户端、登录页、侧栏、程序图标和托盘统一使用紫色 H 品牌。关闭窗口会隐藏至托盘；断开连接或退出时客户端会恢复 HQIP 管理的网络设置。若连接、TUN 或恢复失败，请检查 Windows 辅助服务状态、UAC 授权以及其他代理软件是否占用了相同设置。

第三方 Mihomo/Clash 链接在用户端的每份订阅详情中单独管理。链接只控制该订阅的导入入口；轮换或撤销不会删除订阅实例，也不会影响 HQIP 客户端的独立连接凭据。
