# 管理端运维预警中心

入口为 [cms-hqip.5202345.xyz/notifications](https://cms-hqip.5202345.xyz/notifications)。预警只用于后台基础设施和运维，不向用户发送消息，也不展示用户订阅到期、流量、停用或开通申请提醒。用户只在自己的订阅页面和 HQIP 客户端查看流量包状态；待处理申请在管理端申请队列处理。

预警中心覆盖节点健康、部署与清理失败、服务器或节点容量、磁盘空间、节点证书以及这些运维问题的恢复状态。固定检查阈值如下：

| 条件 | 阈值与处理 |
| --- | --- |
| 节点心跳／内核异常 | 中断或持续异常 60 秒；健康稳定 30 秒后恢复 |
| 安装、验证、清理任务 | 最终失败时告警；取消不算失败，同类操作成功后结束旧失败 |
| 服务器／节点月流量 | 北京时间自然月达到 80%、100%；仅提醒，不改变限速 |
| 服务器磁盘 | Agent 数据目录文件系统可用空间不足 512 MiB；同服务器合并 |
| 节点证书 | 到期前 14、7、3 天及已过期；签发、续期或应用失败 |

服务每 30 秒检查条件，管理页面每 5 秒刷新。相同对象和条件合并为同一预警并保留状态变化。页面支持当前、历史和全部记录，按类别、等级、对象或状态筛选；详情展示发生时间、最近检查、恢复／结束原因、事件编号和对象入口。管理员可以确认已知晓并追加处理备注。确认只记录人工知悉，不会关闭仍在发生的问题；恢复由系统判定，节点需连续健康 30 秒。

监控数据缺失时标记待核实，不能当作零或正常。对象删除、容量周期结束或提醒条件不再适用时标记已结束，不误称为恢复。控制服务停机期间无法检查；恢复后重新核对当前状态。已结束历史保留 90 天。

周期流量以已有上传与下载合计计算额度使用率；即使部分时段数据不完整，已知用量达到 80% 或 100% 仍正常生成提醒或严重预警。缺失数据不会被补成流量；只有不完整合计低于阈值、无法证实旧预警已结束时，才保留待核实状态。

所有预警数据都只保存在站内，不调用飞书或其他外部通知服务。旧用户套餐预警及其活动记录在订阅模型迁移时清理；基础设施预警历史保留。管理员接口为 `GET /api/v1/alerts`、`GET /api/v1/alerts/summary`、`GET /api/v1/alerts/{id}` 和 `PATCH /api/v1/alerts/{id}`。写入需管理员会话、CSRF 和 `expectedRevision`；备注最多 2000 个字符。
