# 站内预警中心

入口为 https://cms-hqip.5202345.xyz/notifications 。所有预警在后台集中展示，不再配置飞书机器人，也不发送外部消息。

页面包含当前预警、历史记录、分类／等级／对象筛选和事件详情。管理员可以确认已知晓、追加处理备注；这些操作保留身份、时间和审计。确认不代表问题解决，仍存在的异常继续展示。状态改变时旧版本编辑返回冲突，页面保留备注供核对后重新提交。

| 条件 | 阈值 |
| --- | --- |
| 已部署节点心跳／内核异常 | 中断或持续异常 60 秒；健康稳定 30 秒后恢复 |
| 安装、验证、清理任务 | 最终失败；取消不算失败，后续同类成功后结束 |
| 服务器／节点月流量 | 北京时间自然月 80%、100%；仅提醒 |
| 服务器磁盘 | Agent 数据目录文件系统可用空间不足 512 MiB；同服务器合并 |
| 证书 | 到期前 14、7、3 天及已过期；签发、续期、应用失败 |
| 用户套餐流量 | 本次开通已确认用量 80%、90%、100%；预留预算单列 |
| 用户套餐到期 | 到期前 7、3、1 天及已到期；停用及未开通用户不发预告 |

服务每 30 秒核对一次，网页每 5 秒刷新。周期条件按对象、类型及周期合并，阈值上升或异常复发重新要求确认。持续异常不会生成重复投递记录。未知数据保留原异常并标为待核实；对象删除、调整额度、延期和周期结束标为已结束，不误报为恢复。

当前预警持续保留，已结束历史保留 90 天。控制服务停机期间无法检测，恢复后重新核对。旧业务通知保留为历史，飞书测试消息与投递错误不算业务预警。升级会清空运行数据库中的机器人凭据，取消待发队列；回退代码也保持飞书关闭。

接口只对管理员开放：`GET /api/v1/alerts`、`GET /api/v1/alerts/summary`、`GET /api/v1/alerts/{id}`、`PATCH /api/v1/alerts/{id}`。PATCH 需要 `expectedRevision`，可设置 `acknowledge:true` 和／或追加 `note`（最多 2000 个字符）。数据使用 UTC RFC3339 时间戳，界面显示北京时间。
