# 调整单份用户订阅到期时间

管理员在用户详情页的订阅卡片点击「调整到期时间」，按北京时间选择日期和分钟，核对调整前后时间后保存。调整可以延长或缩短，但新时间必须晚于服务器当前时间。原订阅已到期或已移除时不能调整；弹窗打开后到期也会被服务端拒绝。

已有续费周期时只调整最后一期终点，新时间必须晚于最后一期起点，既有周期分界不移动。缩短期限也会缩短尚未付款续费订单的付款截止时间；之后延长不重新开放旧订单。调整不新增流量周期，付费追加一期请使用[套餐续费](subscription-renewals.md)。

未到期但已用完流量、账户停用或模板停用的订阅仍可调整日期，其使用限制保持原状。此操作仅修改一份订阅实例的有效期，保留其节点、流量额度与用量、导入凭据、会话及付款记录，不产生订单。

管理接口为 `PATCH /api/v1/users/{id}/subscriptions/{subscriptionId}/expiry`，要求管理员会话和 CSRF，接收 RFC3339 `expiresAt` 与当前 `expectedRevision`，成功返回更新后的 `UserSubscription`。输入时间错误返回 400，归属不匹配返回 404，版本变化、已到期、已移除返回 409，临时数据库错误返回 503。发生冲突或响应异常时应刷新确认当前结果，不使用旧版本覆盖。

订阅、用户配置版本及 `subscription.expiry_updated` 审计记录在同一事务提交。审计包括用户、订阅编号、原时间、新时间及新版本。相同时间的有效请求不增加版本或审计。无需数据库迁移或 Agent 更新。

已有连接不因延长有效期被主动断开。新授权与续约使用新到期时间；缩短后已有连接沿用最长 120 秒的租约同步窗口。修改有效期不延长已经关闭或到期的连接租约。

节点额度父授权在下一次有效报告时同步最新期限，空闲和名额重新申请同样适用。Agent 必须接受合法的截止缩短；已提交的旧报告即使回执晚于截止时间也继续确认结算，不能阻塞后续断开和名额释放。已结束连接的占用由节点正常补报回收，流量记录保留。该修复需要同步更新控制端和节点 Agent，HY2/VLESS 计数规则及内核协议不变。
