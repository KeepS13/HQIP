## 已知边界

可自动部署的 NAT 仍须满足：本机源地址的公网出口等于配置的节点公网 IP，供应商提供相同外部／内部端口的入站映射。出口检测不代替公网入站和实际代理验证；共享纯出站 NAT、未开放映射、不同内外端口和非对称出口不在自动识别范围。

首次部署后的可选网络质量任务仍返回“节点 IP 未绑定到本机，无法检测指定出口”。该独立探针尚未适配 NAT，本轮没有修改或伪造它的结果；不影响节点 ready、代理连接、重新部署或 Agent 更新。不能把本次部署成功写成网络质量评分已通过。
