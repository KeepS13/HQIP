# 性能与稳定性发布记录

发布日期：2026-11-23。发布范围为控制端、两个网站、Windows 稳定客户端 4.8.2 与受管节点 Agent。Godot/Android 预览版及其更新渠道不在此次稳定版发布中，现有本地工作保留。

本次合入 VLESS 独立出站与公共 nodepolicy 依赖、网站单请求轮询、Agent 上报响应复用、客户端采样精简、真实域名握手测速、账户物理网络直连和连接命令幂等。行为与本地验证见 [性能评审](../reviews/2026-11-23-performance-stability.md) 和 [协议契约](../contracts/protocol-policy.md)。测速数值没有人工缩小。

发布前确认生产运行 cf9f6cc，16 个活动节点均健康且配置收敛；两个本机 readyz、两个公网 API 探针、两站静态资源摘要验证通过，无未完成服务器运维任务。部署通过同一干净提交的完整 CI 产物，先控制端与网站，再逐台 Agent。HY2 核心保持运行，Agent 重启会中断现有 VLESS 流，由客户端重连；节点地址、端口、凭据与 Reality 密钥保持不变。

Windows 发布准备另修复一项部署测试的临时路径规范化：Windows 8.3 路径别名与 resolve() 的长路径不相等，使测试提前触发“较新发布”保护，未达到原本要覆盖的迁移防降级检查。测试夹具改为规范路径后四项定向回归通过，生产回滚逻辑不变。

上线状态与实际回执在部署完成后补充；此记录当前不表示生产已切换。备份使用在线 PostgreSQL 快照与原主密钥配对保存，回滚保留实时账务。大陆三网多时段、Android 真机不属于此次 CI 的覆盖范围。

首轮 CI 45258423128 被 Windows 常规测试阻止：`TestOfflineRecoveryTimeoutStillAllowsKnownSlotRelease` 的 300 毫秒测试预算在共享运行器上超时。其余 Linux、真实 PostgreSQL/Redis、Windows 打包及三组真实客户端回归全部通过，生产未切换。旧测试本地连续 20 次通过；调整夹具使用生产的 4 秒预算，同时明确验证恢复请求保留正常报告预算、真实超时发生，以及已知空闲名额最终释放。生产超时和释放逻辑保持不变。
