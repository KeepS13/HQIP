## 更新对用户的影响

- 重启 Agent 会断开由该进程持有的现有 VLESS 流，客户端需要重新连接。公共守卫的提取不提供连接跨进程迁移，不能称为零中断升级。
- 若同时更新并重启 HY2 核心，HY2 现有连接也需要重新连接。已有 Agent 升级流程保持 HY2 进程；本次候选 Agent 与当前线上核心的组合已通过隔离兼容性验收。
- 解耦版本运行后，HY2 核心崩溃、停止或重启不再终止 VLESS 的出站套接字、授权或后续准入。VLESS 仍依赖其宿主 Agent 及原有业务授权条件。
- 保留节点域名、端口、原凭据、Reality 私钥 / 公钥、short ID 和伪装配置后，现有订阅与节点配置可以继续使用，无需重新购买、重新订阅或重新导入。本次实现不轮换这些连接参数。
