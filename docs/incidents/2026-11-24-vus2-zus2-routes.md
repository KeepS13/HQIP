# VUS2 与 ZUS2 线路对比

检测日期：2026-11-24，约 12:43–12:47 UTC（北京时间 20:43–20:47）。

结论：本次样本中，ZUS2 到上海联通的往返延迟比 VUS2 低约 99 ms（42%），到上海移动低约 39 ms（20%）。上海电信基本持平，北京移动则是 VUS2 低约 12 ms。当前 Windows 工作站到 VUS2 的 Ping 低约 18 ms，但 VUS2 的 TCP 建连长尾更多。不能把这些延迟差值换算成下载速度倍数。

## 范围与方法

- 通过现有控制端只读查询确认节点名称、ID、公网地址和健康状态，再使用固定主机指纹的 SSH 对两台节点执行只读网络检查。节点凭据仅在内存中使用，没有写入报告或日志。
- VUS2：`154.50.110.147`，节点 `tcXT5__DvWwUO5fV_X`；ZUS2：`192.204.39.242`，节点 `v6g0CoAZQtGsvJK2UT`。两台检测前核心健康状态均为正常。
- 工作站默认 IPv4 出口为以太网，经 `192.168.10.1`。对每台节点执行 30 次 Ping、tracert，以及两轮 TCP 443 建连（20 次、60 次）。TCP 数据仅包含建连，不包含 TLS、Reality、HY2 握手或业务请求。
- 每台服务器使用节点公网 IPv4 显式绑定源地址，对相同的北京、上海三网目标执行 MTR 和 Ping。远端目标测试存在并行，Ping 间隔为 0.2 秒；短时 ICMP 结果可能受响应限速影响。
- 没有修改节点配置、重启服务、安装工具、创建业务订阅或执行大流量测速。仅在本地保存证据和本报告。

## 延迟

服务器发起的 Ping 数值是到目标的往返时间，不是单向回程时延。每个可响应目标均获得 25 个有效回复；原始发送数量和未响应比例见下一节。

| 测量方向 | VUS2 平均 RTT | ZUS2 平均 RTT | 本次差距 |
| --- | ---: | ---: | --- |
| 当前工作站 → 节点，30 次 Ping | 161 ms | 179 ms | VUS2 低约 18 ms |
| 节点 → 上海电信 `202.96.209.133` | 139.394 ms | 138.783 ms | 相差 0.611 ms，基本持平 |
| 节点 → 上海联通 `210.22.97.1` | 234.524 ms | 135.926 ms | ZUS2 低 98.598 ms，约 42.0% |
| 节点 → 上海移动 `211.136.112.200` | 196.227 ms | 156.761 ms | ZUS2 低 39.466 ms，约 20.1% |
| 节点 → 北京移动 `221.179.155.161` | 169.526 ms | 181.170 ms | VUS2 低 11.644 ms |

北京电信 `219.141.136.12`、北京联通 `202.106.0.20` 的终点均未回复 Ping，只有部分中间路由可见，因此没有填写它们的端到端延迟，也没有把未响应判定为业务不可用。

## 短时稳定性观察

| 工作站 TCP 443 第二轮 | VUS2 | ZUS2 |
| --- | ---: | ---: |
| 尝试次数 | 60 | 60 |
| 三秒内成功建连 | 59 | 60 |
| 成功样本中位数 | 166.040 ms | 171.625 ms |
| 成功样本平均值 | 387.636 ms | 318.878 ms |
| 成功但超过 500 ms | 10 | 7 |
| 超时 | 1 | 0 |

两者都出现约 1–2 秒的建连长尾。VUS2 的典型建连略快，ZUS2 的本轮成功率和长尾略好；样本不足以证明长期可用性差异。第一轮各 20 次建连均成功，中位数分别为 162.39 ms / 168.07 ms。

工作站 Ping 分别收到 25/30、27/30 个响应。服务器到上海电信的 Ping 分别收到 25/33、25/27；到上海联通为 25/29、25/25；到上海移动均为 25/25；到北京移动为 25/36、25/25。以上是实际记录的 ICMP 响应情况，不直接等于 TCP、QUIC 或用户业务丢包率。MTR 中间跳的高未响应比例也不能代替终点统计。

## 判断边界

本次最明确的差距在联通回程：ZUS2 观察到 AS9929，上海联通 RTT 明显更低。移动效果随目标地区变化；电信上海目标没有明显延迟优势。当前工作站的普通 Ping 更偏向 VUS2，不能仅凭节点列表延迟决定所有用户的选择。

未测持续吞吐、HY2 与 VLESS 的同条件下载、全国更多城市或多个晚高峰，不能承诺带宽倍数、长期低丢包，或把样本推广为全国三网的统一排名。
