# HY2 测速后空闲占位

2026-11-23 对生产控制端和分配节点作只读检查，未清除租约、重置计数或调整套餐。受影响订阅的模板分配数为 100、同时在线上限 15，节点池与该订阅实际分配数均为 15。模板默认值与已购买订阅的分配快照独立。账号身份仅保存在私有运维记录中。

21:23–21:27 UTC 的两次采样均为 15/15，全部 HY2，来源 IP 摘要一致。节点内核 `/online`、本地未结束子账本与中央名额一致。观察约三分半钟，15 条连接的字节计数没有增长，报告版本仍增加 31–35；TCP 流采样为零。未发现待补 final 卡住，节点均健康。控制端版本为 `5f68c04b88a02fda38dbea6a5ddf0444823fa329`。

根因是把 QUIC 传输生命周期当作业务在线生命周期。客户端测速完成后保留 QUIC 并发送保活，守卫继续每五秒续约，即使没有 TCP 业务流也长期占一个名额。同一电脑测试多个节点可建立多个 HY2 会话，因此两台电脑足以占满 15 个名额，后续实际目标准入被拒绝而显示 -1。现有计数不是硬件设备识别。

修复把只读身份检查与转发准入分开。QUIC 握手不申请资源；首个 TCP/UDP 目标拨号前正常准入，并发目标共用该传输的一份授权。最后一个目标结束后提交真实累计 final、停止续约并释放名额，保留 QUIC 以送完已缓冲响应。再次使用必须用新子连接 ID 重新申请。原父账本可复用；4096 个历史子记录满额后选择新父账本，完整保留旧记录。既有计费、带宽、离线和撤权规则保持不变。

边界：测速正在传输时同样受并发限制；不按网址或字节阈值豁免。仍存在的 HTTP keep-alive/WebSocket 属于活动 TCP 目标，不能只因无流量强断。HY2 UDP 沿用默认 60 秒空闲超时与一秒扫描；异常断开和未知 final 继续保守保护预算。VLESS 已有按来源 IP 去重及最后流结束后的五秒回收规则未改动。
