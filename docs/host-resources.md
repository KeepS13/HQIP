# 控制台主机资源

管理端侧栏显示运行 HQIP 控制服务的主机 CPU、内存和服务数据分区容量。仓库正式部署配置将 Nginx 静态前端与控制服务部署在同一台机器；如果自行拆分部署，这里仍只代表控制服务主机，不代表浏览器、代理节点或所有服务器的合计。

`GET /api/v1/host-resources` 仅在管理员 API 上提供，要求已完成初始改密的管理员会话；公共和用户 API 不提供此接口。响应只包含采样时间、CPU 百分比、内存与磁盘的已用/总量，不包含主机名、文件路径或进程信息。

页面每 5 秒读取一次，服务端最多每 5 秒触发一轮异步采样。同一轮并发请求共享采样结果，读取不会等待采样；首次返回正在采集，之后保留上次结果直到下一轮完成。没有常驻采样协程，页面不再请求时不会继续采样。CPU 必须取得两次间隔不超过 20 秒的有效累积计数才显示百分比；首次、计数器重置、读取失败或长时间暂停后首轮采样显示未知，不显示虚假的 0%，也不会把暂停期间的平均负载作为当前负载。

Linux 从 `/proc/stat`、`/proc/meminfo` 和数据目录所在文件系统读取；Windows 开发环境通过系统 API 获取相同指标。Linux 已用内存按总量减可用内存计算，磁盘按文件系统总块数减空闲块数计算，仅覆盖 `--data-dir` 所在分区，不合计其他挂载盘。容量使用 MiB/GiB/TiB。其他平台或无法采集的单项显示未知；请求失败或采样超过 20 秒时保留上次数据并明确标注过期。
