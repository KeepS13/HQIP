## 实施方式

服务仅增加门户旧密码兼容。一次性脚本将 cost=10 的 bcrypt 哈希以 `legacy-bcrypt:` 前缀写入 `portal_users.password`；未标记的 bcrypt 不被接受。门户成功验证后，以密码和启用状态为条件更新为 Argon2id，与会话创建同事务提交。改密时兼容尚未升级的旧密码。管理员和设备的公共校验不变。

迁移脚本及含哈希导出保存在受限、Git 忽略的本地操作目录，不开发通用导入系统或公开接口。核实目标控制器身份及模板版本后，在数据库事务中写入账号、订阅、用量初值和节点分配，保存稳定来源映射及批次回执。任何校验失败均回滚；重复运行依来源标记识别，不重置迁入后的密码、用量或期限。

先完成兼容版本测试与部署，再做隔离演练。最终快照前暂停老站后台写入，核对在途订单；新站导入期间阻止冲突的用户操作但保持 Agent 上报。备份老库、新库及配套主密钥。正式导入后逐条验证账号状态、期限、节点归属、原有数据保持及重复运行保护，才开放迁入账号。

老站停服只作为迁移窗口的临时措施；恢复老站会继续产生独立的密码、续费及权益变更，不能将其视为已经同步。交接状态必须在迁移回执中说明；不自动删除旧库或退役旧节点，不自动发送通知。
