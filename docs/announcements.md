# 用户公告

管理员在侧栏“用户公告”点击“发布公告”，填写标题、正文和展示方式，再选择接收用户。支持按邮箱或用户 ID 搜索，逐个勾选或全选搜索结果；搜索变化不会丢失已选用户。公告只发给本次明确选择的用户，之后注册的新用户不会自动加入。

- **每次登录或刷新都弹出**：每次进入已登录的网站加载公告，可点下一条或关闭。
- **点击我已知晓后不再弹出**：用户确认后按账号保存状态，更换浏览器仍然有效。关闭、Escape、点击遮罩或查看下一条不会标为已知晓。

多个公告按最新发布优先逐条展示。用户可直接点 X 结束本次展示；确认失败时保留当前内容，重试成功后才进入下一条。网页内部导航不重新弹出公告。本轮只包含用户网站，不在 Windows/Android 客户端弹出。

管理列表显示展示状态、目标用户数和已知晓人数，可查看原文及接收名单、停用公告。发布内容固定；需要变更时停用旧公告，再发布新公告。发布回执丢失时，当前标签页保留原请求，重新打开发布窗口点击“重试本次发布”，不会重复发出同一公告。

数据迁移、权限、分页和错误语义见 [接口契约](contracts/user-announcements.md)。完整发布包会在切换新版本前执行增量迁移；手动 PostgreSQL 升级使用迁移账号执行 `hqip migrate-announcements`，运行账号沿用已有默认表/序列授权。SQLite 启动时自动升级。已发布公告和确认状态随正常数据库备份恢复。
