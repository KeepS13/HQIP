# Cloudflare 域名与节点证书

HQIP 为每个公网 IP 节点分配独立域名、独立证书及独立连接凭据。Cloudflare DNS 记录必须为 **DNS only（灰色云朵）**；普通橙色云朵代理不支持节点的 Hysteria 2 UDP 流量。

## 配置 API Token

1. 在 Cloudflare 用户资料的 API Tokens 页面创建 Custom Token。
2. 只授权准备给 HQIP 使用的 Zone，权限为 `Zone / Zone / Read` 和 `Zone / DNS / Edit`。无需账户管理权限，不使用 Global API Key。
3. 在 HQIP「域名与证书」中填写 Token，点击验证，从返回的 Zone 列表选择默认域名，并填写用于 ACME 注册的联系邮箱。
4. 保存后 Token 加密存放在控制中心数据库中，界面不再回显。修改邮箱或默认 Zone 时留空 Token 可保留原值；填写新 Token 则替换旧值。

“验证成功”表示 Token 处于启用状态，且能读取已授权域名。DNS 写权限在首次创建节点记录时校验；没有 DNS:Edit 时部署任务会显示 Cloudflare 权限错误。Token 不会发到节点服务器。

若 Token 限制来源 IP，应允许控制中心服务器的出站公网 IP。替换 Token 时应继续授权仍被已有节点使用的 Zone，否则这些节点的续期或清理会失败。旧的有效证书不会因此被覆盖。

未配置 Token 时，Cloudflare 自动分配及 DNS 验证不能执行，已有手工域名的 HTTP 证书模式仍可使用。修复 Token、Zone 或联系邮箱并保存已验证设置后，先前失败任务可立即重试；普通的提前重试不会延长原来的退避等待时间。

## 添加节点与保留原域名

先登记服务器，再在“添加节点”弹窗手动填写已配置在服务器网卡上的公网 IPv4，无需预先登记 IP。选择 Cloudflare 自动域名模式时，HQIP 创建随机的 `n-…` 子域名 A 记录，记录只指向填写的 IPv4，并等待权威 DNS 生效。不要为该节点添加 AAAA、其他 A 记录或开启 Cloudflare 代理。

已有手工域名继续使用原 A 记录。切换其证书为 Cloudflare DNS 验证需重新提供 SSH 密码并执行重部署；证书模式在服务部署成功后才切换。切换不改变原域名和 A 记录，也不授予 HQIP 删除原 A 记录的权限。

具体操作是在节点详情打开「重试部署」，选择 Cloudflare DNS 自动续期并填写域名所属 Zone ID（默认采用设置中的 Zone）。先预检，再确认部署；若检测到旧 HY2，须确认备份接管。现有域名必须位于所选 Zone 内。未保存 Token 时，此选项不可用。签发失败或部署回退时，不会把原 HTTP 模式标成已切换。

客户端直接连接节点 IPv4，使用节点域名作为 TLS SNI 并校验证书。新增、替换或删除公网 IP 仍须在服务器/IP 管理中操作，不能通过改 DNS 来绕过节点分配及出站 IP 校验。

## 证书签发与自动续期

Cloudflare 模式由控制中心向 Let’s Encrypt 申请证书，通过 `_acme-challenge` TXT 完成 DNS-01 验证，不要求节点开放 TCP 80 或 443。每次 TXT 操作都有持久归属记录；控制中心中断后可继续清理，且不会删除其他 ACME 客户端创建的 TXT。

固定版本 `golang.org/x/crypto/acme` 暂不提供 ACME ARI 接口，因此本版本在证书有效期经过三分之二时续期。后台按到期时间调度并重试；失败从 15 分钟开始指数退避，最高间隔 24 小时。到期前 14、7、3 天及过期时，证书页显示相应提醒。

私钥和 ACME 账号密钥均在控制中心数据库中加密保存。Agent 只领取属于本节点的证书包，检查域名、时间、私钥匹配与版本后原子切换。页面分别显示签发版本与节点应用版本，签发成功不代表离线节点已经收到新证书。切换失败保留有效旧版本。

手工域名的 HTTP 模式由 Hysteria 自身自动续期，要求节点 IP 的 TCP 80 可供 HTTP 验证使用；已有 Caddy 验证转发只在明确配置时使用。HQIP 管理网站本身的 Nginx/Certbot 证书续期独立运行。

这里的自动续期是 TLS 证书续期，不包括向域名注册商支付域名注册年费；域名本身仍需在注册商保持有效。

## 删除与故障处理

- HQIP 只删除自己创建且 Record ID、名称、类型、内容、代理开关和归属标记仍一致的记录。遇到外部修改或删除，不擅自覆盖、重建或删除，显示需要人工处理。
- 删除节点先停止节点服务，再清理其 DNS 和托管证书。已删除节点仍有未清理 DNS 时，会继续显示在「域名与证书」的 DNS 记录列表中。
- Token 失效、Cloudflare 限流或网络故障时，清理保留为待处理并自动重试。未确认停止的节点不能因 DNS 清理而被当作已下线。
- 仅节点记录创建失败且未取得远端安装归属时，可删除后台失败记录；后台会清理已分配的自身 DNS，但不会停止旧 HY2 或其他站点。
- 控制中心断网时节点继续使用已应用证书和授权。若断网持续至证书到期，严格 TLS 验证的客户端将拒绝连接；恢复控制中心并完成续期及应用后重试。

数据库和 `master.key` 必须来自同一份备份；缺少主密钥时无法恢复 Token、ACME 账号或证书私钥。运行数据、Token、证书私钥和索引缓存不可提交 Git。

## 验证范围

自动化测试覆盖固定 Cloudflare API 来源、禁止重定向、敏感错误脱敏、DNS 冲突、外部修改保护、丢失创建响应后的恢复、TXT 共存、删除恢复、RFC 8555 DNS-01 订单、私钥匹配、版本隔离、续期时间及退避、管理员认证与 CSRF。

真实 Cloudflare 签发及续期验证需要管理员在后台配置自己的 Token 后进行；没有配置 Token 时，不应把模拟测试报告为真实 DNS 或证书验收。
