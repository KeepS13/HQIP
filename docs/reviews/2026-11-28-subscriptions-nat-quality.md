## 结果与边界

默认账户入口独立于套餐，空账户可复制，购买、到期、更换和单份轮换不改 URL；每次更新动态读取成员，仍逐份授权和计费。旧单份与快照保持兼容，不能把单份权限扩大为账户权限；历史快照须重新复制一次新默认入口才具有动态成员行为。规范见 [import-links v2](../contracts/subscription-import-links.md)。选择器只显示 active，失效的深链接保持明确的无效选择。

保存模板后可点击「立刻应用」，更新现存订阅的每份节点目标，保留可保留的节点并按原规则补缺，缩容释放多余分配并协调租约。缺额明确返回，后续新增候选节点可以补齐已保存目标。用量、预留、付费周期、有效期和 URL 不重置；待开通定制实例仍须人工开通。价格／天数不追溯改写购买事实，未完成订单继续保留下单快照。在线、流量、限速及启用状态沿用现有保存即生效规则。规范见 [template-apply v2](../contracts/subscription-template-apply.md)。

NAT 故障包含远程 Python 要求公网 IP 在本机、Bash 参数处理和最后总校验要求观测 IP 等于绑定 IP，以及 DNSBL 子进程直接绑定被查询的公网 IP。现使用实际拥有的路由源地址绑定 HTTP/DNS，DNSBL 仍查询公网反向地址但使用内网源地址发包；验证公网出口等于节点身份，探针再验证一次，控制端继续拒绝 Head.IP 不符报告。xus1-v 的历史映射 `10.0.186.2 → 45.205.28.141` 仅用于回归场景，没有把模拟成功写成现场检测成功。固定供应商脚本版本为 hqip3，补丁、声明、文件摘要同步更新。
