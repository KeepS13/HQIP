# 套餐应用状态与卡片交互

归属 `subscription-admission` 与管理员站，契约 [template-apply v3](../contracts/subscription-template-apply.md)。本轮仅处理已编辑版本的应用提示、二次确认和卡片下方内容清理，不改实时额度、分配规则或用户订阅链接。

## 实现与兼容

- 服务端在模板 JSON 保存 `appliedRevision`，应用与分配同事务提交；保存忽略客户端伪造值并保留最新应用值。创建时为0，版本大于1且未应用才标记。旧版本未记录应用版本，不能推定旧点击对应哪个版本，确认应用一次即可建立状态。
- 橙色按钮同时含警示图标和「待应用」，确认固定打开弹窗时的版本；失败留在弹窗，成功和缺额数量显示浮动提示。卡片底部仅保留两个操作按钮，操作后卡片尺寸不变。
- 无新表、迁移、轮询、读取查询；每次应用额外写一次模板 JSON。事务沿用用户锁与 Serializable 重试，状态写入失败会回滚所有分配。
