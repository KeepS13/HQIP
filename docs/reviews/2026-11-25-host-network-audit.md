## 实现范围

契约：[`host-network v1`](../contracts/host-network.md)。采集归 `internal/hostnetwork`，本地持久化归 Agent，主机去重累计归 store，管理员展示归 admin-web。

- 节点列表保留每节点本周期与累计代理用量，新增所属服务器网卡接收＋发送累计；顶部网卡汇总按服务器去重，明确当前筛选范围及采集覆盖台数。
- 节点／服务器详情列出累计收发、当前速率、采集时间、网卡明细和排除接口。采集过期后保留累计、隐藏速率；浏览器在刷新失败时也自动执行 30 秒过期检查。
- Agent 每 5 秒读系统计数，复用既有上报与 FULL-synchronous SQLite；普通断网不丢弃未确认记录，按启动／网卡索引去重。保留重置和网卡移除前检查点，同秒内按纳秒顺序补报，每批最多 8 条。
- 主机汇总行先加锁，再更新启动水位，和报告同事务提交；多节点、重放、提交成功但确认丢失不会重复累计。旧控制端不确认扩展时不删除本地记录。
- 没有新增浏览器请求或数据库 schema 迁移。稳定运行只有一条当前样本和一条待确认样本；启动／重置历史随实际事件增长，未确认检查点不静默截断。管理员节点列表新增一次批量读取，服务器监控新增一次主机键读取。
- 新生产文件均少于 300 行；原 600 余行节点页面拆为列表、详情和工具，原入口保留重导出。控制端节点详情从历史大文件抽出独立处理器。

## 尚不能承诺的范围

首次网卡快照包含当前启动已有计数，显示“已观测累计”，不冒充本月／计费周期流量。未采集的旧周期不可补造。重启、驱动重置及多 Agent 跨重置乱序可能损失最后可确认采样之后的尾部；标记断点，不宣称零遗漏。当前不支持只有容器 veth、没有承载设备的环境；不能保证 Linux 驱动计数与厂商计费层级完全一致。

服务器自身消耗已纳入整机计数，但没有准确的独立数值或按进程明细。需要从采集开始增加同一网络层级的进程／服务归属计量后才能提供可验证分项，无法倒推历史。
