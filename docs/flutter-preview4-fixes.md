# Flutter preview.4 修复记录

版本 `0.1.0-preview.4`，序号 `4`。保持预览版签名、包名、数据目录和现有深色/紫色配色。

## 安装与升级

Windows 安装器读取预览版的 32/64 位注册表记录，找到原安装位置；结合安装版本元数据与验签后的活动、待安装更新，比较最高序号。首次安装可选路径，已有安装复用原路径，显示升级或同版修复，阻止降级。安装前再次确认版本和进程退出状态，不强制终止 VPN；保留账户、订阅、设置、开机启动偏好及更新指针。详见 `flutter-installer-upgrades.md`。

## 网页登录

Windows 预览版允许在直连 TLS 建连失败时，使用用户已经启用的本机 HTTP 系统代理。不会设置或关闭系统代理，也不会改 hosts。只接受显式本机代理、尊重绕过规则，并检查监听进程，拒绝使用 HQIP 自身代理形成循环。端到端证书校验、SNI 与 HTTP/2 保留；切换仅发生在 HTTP 请求发出前，不重放登录、授权码交换或刷新令牌 POST。

此兼容路径仅由 Flutter Windows 主机启用。正式客户端和 Android 的默认直连策略不变。仅有 TUN、PAC 或远程代理而没有启用本机 HTTP 系统代理的环境不在该兼容路径内。

授权成功后 Windows 尝试唤回客户端窗口，Android 尝试返回现有 Activity；系统可能限制后台应用抢占前台，用户仍可手动返回。登录后显示连接页，不自动建立 VPN。初次配置同步失败但凭据已保存时，界面立即读取真实登录状态，并提供“重新同步”；授权前失败时提供“重新登录”，保留之前选择的服务器，不再声称未完成的登录已保存。
