# Windows 预览版安装与升级

预览安装器继续使用固定 AppId `{87A84998-B48F-4B56-99C7-717315BFA38D}`，只检查预览版。正式版安装位置、版本和数据不参与检测。

安装开始前由安装包中自带的新启动器执行只读检查，不运行电脑上已有的可执行文件。检查当前用户和计算机的 32/64 位卸载记录、安装目录中的 `install.json`，并使用预览公钥验证 `active.json` 和 `pending.json`。取已安装和已准备安装版本中的最高序号，避免安装器把热更新后的版本降回旧版。

- 首次安装：允许选择目标目录。
- 已安装较低版本：显示现有版本、升级目标和原目录，在原位置升级。
- 相同序号：显示“修复 / 重新安装”，修复内置程序文件。
- 已安装或已准备安装更高序号：阻止旧包覆盖，静默安装同样阻止。
- 状态损坏、签名错误、无法确认版本或多条安装记录相互冲突：安装停止，不猜测版本、不删除原文件。

preview.1–3 没有 `install.json`；安装器兼容这些版本的 `DisplayVersion` 注册表记录，并保留自定义安装位置，例如 `D:\software\HQIP Preview`。检测到已有安装后目录锁定，避免产生第二份客户端。后续构建将产品、渠道、版本与序号写入安装根目录 `install.json`。

安装前需要用户从系统托盘选择“退出”；只关闭窗口不会结束后台连接。安装器不强制结束 VPN 进程，在写入文件前重新检测运行状态和版本。账户、订阅、设置、开机启动偏好以及更新指针保留；新启动器会忽略序号低于新内置版本的旧指针。卸载仍只清理安装目录，不清理 `%LOCALAPPDATA%\HQIP\FlutterPreview`。

检查命令：

```powershell
go test -tags=with_utls ./cmd/hqip-flutter-launcher
python scripts/build_flutter.py windows
```

Go 回归覆盖首次安装、自定义路径、旧版本兼容、同版修复、升级、降级阻止、活动/待安装签名版本、损坏状态、注册表记录冲突、安装中断后的最高版本保护，以及中文路径报告。安装器通过 Inno Setup 编译验证。测试只使用临时目录；实际覆盖安装和退出正在运行的用户客户端需要单独验收。
