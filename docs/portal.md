# 用户账户、多份订阅与节点准入

用户端为 `https://hqip.sharevps.online`，管理端为 `https://cms-hqip.sharevps.online`，API 为 `https://api-hqip.sharevps.online`。用户通过邮箱和密码注册；密码至少 6 个 Unicode 字符、最多 1024 字节。注册和网页登录需要 Turnstile，未配置或验证服务不可用时不会绕过验证。用户登录本身不授予 VPN 权限。

## 订阅模板与用户实例

订阅模板由管理员维护，字段包括名称、有效天数、人民币售价、一次性流量、带宽、并发 VPN 连接上限、允许节点，以及服务启用和用户可见开关。`null` 带宽或流量表示无限，价格为空表示尚未定价、不可购买。模板不再配置默认节点；旧请求中的 `defaultNodeId` 会被忽略。用户在订阅商城购买，支付 FM 收款核验后自动开通；管理员也可直接给用户添加实例。每次付款或分配均创建独立订阅实例，同一个模板可以重复持有。有效期从实际开通时开始，流量按该实例整个有效期内的上传加下载累计，不按月重置。支付配置和订单处理见 [支付 FM](payments.md)。

修改模板时，节点授权、带宽、流量与并发额度立即影响现有实例；已用流量和既有到期时间不变。订单锁定下单时的价格和有效天数，模板改价和改期限只影响后续新订单。模板停售仅停止新购买；停用模板会使已有实例失效，已付款待开通订单保留待处理。移除实例会撤销该实例自己的授权和连接，不影响用户的其他订阅。

管理员可在用户详情的单份订阅卡片中点击“修改节点”，从全站可用节点中手动增删、更换，包括套餐节点池之外的节点。数量为 0～1000 个，保存后成为这份订阅的分配目标；清空会撤销该份订阅的连接权限。已到期或移除的订阅不可修改，未到期但停用或耗尽的订阅可调整。新增节点须通过现有健康、准入与服务器容量检查，当前节点暂时离线时可保留或移除。同一用户的同套餐其他未到期订阅和有效订单预留占用的节点不可重复选择；保存事务会复查，过时的弹窗返回冲突并要求重新加载。

手动修改保留套餐、到期时间、流量账本、导入链接、带宽及连接上限。移除节点上的租约被撤销，结算确认前继续占用连接名额；保留节点上的合法连接继续使用。HQIP 客户端通过现有同步切换，第三方客户端刷新订阅后取得新节点。后续模板节点池成员发生变化时，会保留池内节点、移除池外节点，并按本次手动保存的数量补齐；库存不足显示缺口。只修改模板名称或每份默认节点数不会覆盖既有实例的分配。

删除节点前会检查所有订阅模板，包括隐藏、停用和暂无用户的模板。被引用时展示冲突，管理员需先从各模板移除节点再删除。仅 `nodeIds` 成员关系构成引用，旧默认节点字段不再阻止删除。删除提交会在同一事务内再次检查，过时的预览不能绕过保护。旧记录中失效或已删除的选中节点会在模板编辑页单独展示，必须显式移除。可以清空模板的全部节点，此时该模板的订阅暂时没有可连接节点。

删除节点还会检查未到期、未撤销的用户订阅，包括停用或耗尽的实例及手动分配的套餐外节点。删除预览提供对应用户订阅入口，需先解除引用；过期或已移除实例保留历史记录，不阻止节点删除。

每份订阅单独计量、限速和占用并发名额。多台设备使用同一份订阅时共享这些限制；不同实例互相独立。并发数按真实 VPN 连接计数，等待节点确认关闭的连接继续占名额，不等同于物理设备数量。耗尽、到期、停用或移除时，客户端停止代理并恢复其接管的网络设置；用户可手动选择另一份有效订阅。

## 页面与 API

用户端包含账户总览、节点、订阅商城、我的订阅和账户设置。订阅卡片分别显示短编号、开通与到期时间、流量总量／已用／待结算预留／剩余量、状态，以及该订阅自己的 VPN 连接占用（例如 `1 / 3`）。占用数每 5 秒刷新；刷新失败保留已有数值并显示最近更新时间。节点授权按订阅实例展示。账户设置保留改密和登录会话管理，不提供 VPN 连接历史或逐条断开操作。

侧边栏的“订阅导入导出”（`/imports`）集中管理第三方客户端。先选择自己的订阅，再选择客户端，即可复制订阅链接、导入或下载配置文件。选项显示订阅名称、短编号和状态，只有一份有效订阅时自动选中，多份时需自行选择。从订阅详情的入口跳转会携带 `subscription` 参数，刷新、前进后退和登录后返回均保留选择；无效或已删除的订阅不会自动替换成其他流量包。

| 客户端 | 订阅格式 | 导入与导出 |
| --- | --- | --- |
| v2rayN、Shadowrocket | Base64 编码的 Hysteria 2 / VLESS + Reality 链接列表 | 复制链接，在客户端添加订阅；下载 `.txt` |
| v2rayNG | 同上 | 一键导入、复制链接或下载 `.txt` |
| Clash/Mihomo、Clash Verge、Clash Meta Android | Clash YAML | 一键导入、复制链接或下载 `.yaml` |
| Sing Box（Android、iOS/iPadOS、macOS） | 完整 sing-box JSON | 导入远程配置、复制链接或下载 `.json` |

请使用支持所选协议的客户端版本及内核。同一服务器完成 Agent 升级后，订阅中显示 Hysteria 2 与 VLESS + Reality 两个选项，共用原有套餐额度。Sing Box 配置以 1.14.4 为兼容基线，包含 TUN、DNS、手动节点选择及后台分流规则，GEOIP CN 数据内嵌在配置中。进程规则只在客户端能获取进程信息的平台生效；普通 Android、iOS 上通常继续匹配后续规则。Clash、V2Ray 和 Sing Box 导出共用服务端自动选择结果，没有合格候选时返回 503 和“暂无可用节点”。第三方客户端在下次更新订阅时获得新选择。订阅刷新会取得最新节点及规则；下载的文件是当时的配置快照，不会自动更新。

每份实例的全部客户端格式共用一个第三方导入入口，可创建、轮换或撤销。失效订阅不能新建、轮换、导入或下载，仍可撤销旧链接。轮换及撤销会使旧链接与关联连接凭据失效，但不会删除流量包，也不会撤销 HQIP 客户端专用凭据。第三方客户端同样受所属实例的带宽、流量、到期和并发限制；其刷新与节点切换体验由客户端软件负责。链接和下载文件均包含连接凭据，应妥善保管。

管理端的“订阅管理”负责模板及影响预览；“支付设置”管理商户配置，“订单管理”处理付款及开通异常。旧申请仅保留只读历史，待处理申请已取消，申请写接口返回 410。用户详情可分配或移除某一实例并查看用量与连接占用。写操作使用管理员或用户各自的会话、CSRF 校验及 `expectedRevision` 并发保护。用户接口按当前认证用户约束实例，不能通过请求参数切换用户身份。

核心接口：

| 路径 | 用途 |
| --- | --- |
| `/api/v1/subscription-templates` | 管理订阅模板、预览影响 |
| `/api/v1/subscription-requests` | 管理只读查看历史申请 |
| `/api/v1/users/{id}/subscriptions` | 管理分配、查看或移除指定实例 |
| `/api/v1/user/catalog` | 用户查看商品模板 |
| `/api/v1/user/subscription-requests` | 用户只读查看历史申请 |
| `/api/v1/user/orders` | 用户创建订单及查看购买记录 |
| `/api/v1/orders` | 管理员核对订单与处理已付款开通异常 |
| `/api/v1/user/subscriptions` | 用户查看自己的实例 |
| `/api/v1/user/subscriptions/{id}` | 查看实例详情、节点及导入入口 |
| `/api/v3/client/*` | Windows 客户端认证、订阅选择、配置及连接状态 |
| `/usub/{token}` | 第三方客户端订阅配置 |

旧单套餐用户与设备接口不再作为业务兼容层提供。迁移会保留基础设施和节点统计身份，但旧开发账户、旧套餐及导入凭据不会转换成新订阅。

## 自动节点选择

管理员只维护允许节点列表。首次选择订阅或当前节点被移除时，服务端依次按**在线用户数升序、服务器剩余流量降序、服务器到期时间升序、节点 ID 升序**选择。在线人数按用户去重，多份订阅、多条连接不重复计人；不计探测和旧设备身份。

候选须活动、就绪、支持订阅准入，并在最近 30 秒内有健康、有效的在线上报；服务器记录必须存在，且未到期、剩余流量大于零。流量按整机当前计费周期上传加下载扣除，包括已删除节点的历史用量；未配置周期时按北京时间自然月，周期数据不完整时按已知用量。不限量视为无限剩余，未配置到期时间排在有到期时间之后。

筛选只影响自动选择，手动授权列表保持完整。已选择且仍获授权的节点不会因排名变化而切换。客户端配置响应保留 `defaultNodeId` 表示当前自动候选，无候选时为空；模板及普通订阅信息不再携带固定默认节点。模板节点更新仍撤销已移除节点的租约，客户端下一次同步后先停止旧连接、结清连接名额，再连接候选。原生客户端需要更新到包含此行为的版本，旧版本仍可能在撤权保护分支停止连接。

## Windows 客户端行为

客户端首次登录后由用户选择一份订阅，再选择该订阅允许的节点；连接需要手动开启。订阅与节点选择保存在本机安装实例，不影响账户下的其他设备。每份订阅首次选择时使用服务端自动候选；之后只要所选节点仍获授权就保留该选择。

活跃连接切换订阅或节点时，客户端先关闭旧连接并等待关闭确认，再获取目标凭据并连接。快速连续切换只应用最后选择；用户手动断开优先。关闭代理时仅保存选择。订阅数字刷新不会触发重连。当前节点被移出同一有效订阅时，客户端按服务端候选切换；没有合格候选时停止并提示“暂无可用节点”。订阅到期、耗尽或撤销仍停止连接，不跨订阅回退。

仪表盘分别展示本机内核的实时上下行、近 60 秒速率曲线、本次连接流量与时长，以及服务端确认的订阅用量、待结算预留、期限、带宽和连接占用。本机采样流量与服务端计费流量会明确区分。客户端每秒采样内核指标、每 5 秒同步订阅状态；指标过期或读取失败时显示未知。延迟测试由用户手动触发，仅测试当前连接节点，所耗流量归入当前订阅。

节点只在真实 HY2 准入能力升级并通过验证后才能分配给受限订阅。中央准入按 `subscriptionId` 隔离凭据、租约、预算、限速和账本；控制服务失联后，已建立连接最多继续 120 秒，节点随后停止转发，失联期间不批准新连接。

## 安全迁移

生产数据重置前必须先建立恢复 hold、撤销旧开发用户的新连接权限，等待所有旧租约结清，再核对节点最终账本和基线。迁移保留服务器、地址、节点、域名、证书、规则、管理员和基础设施用量；清理旧业务账户与凭据不清空 Agent 流量基线。升级后只能回退到能读取当前数据库结构的程序，不能用旧快照覆盖新用量。

真实隔离联调夹具由 `TestWritePortalIntegrationFixture` 生成，只在设置 `HQIP_PORTAL_FIXTURE_OUTPUT` 时运行；输出含独立测试凭据，应保存在受限目录并在验收后清理。夹具不绕过生产注册的人机验证。
