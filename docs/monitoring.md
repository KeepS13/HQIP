# 服务器与节点监控

服务器卡片汇总整台 VPS 的 HQIP 节点，点击任意卡片进入服务器详情。身份验证表示 SSH 主机身份已固定，运行状态取决于节点报告；两者不等同。列表可按名称、SSH 地址或公网 IP 搜索，并筛选异常服务器。

## 容量和流量额度

添加服务器时填写带宽容量（Mbps）、每周期流量（GB/TB）和北京时间整点到期时间；容量支持无限。已有服务器通过“额度与续期”修改，无需重新提供 SSH 密码。更换 SSH 管理地址仍需要验证原主机身份。

服务器和节点的额度独立：服务器额度用于整台 VPS 的容量参考，节点额度用于单个 IP 实例。修改一个层级不会修改另一层级，也不会改变订阅授权、重启代理、限速或断网。已配置有效期的服务器及所属节点使用同一周期，分别在周期用量达到 80% 和 100% 时提醒；修改额度保留已使用量，选择无限后隐藏百分比，计量继续。

GB = 1,000,000,000 字节，TB = 1,000,000,000,000 字节。月度历史仍按北京时间自然月计算上传和下载之和，累计用量不会清零。现有未配置到期时间的服务器暂按自然月展示，首次配置保留当月已用量，不猜测厂商到期时间。

## 到期与续期

- 新建默认预填 30 天后，可改为实际到期时间，不要求购买时间。
- 到期前确认续费按每月固定 30 天延长，从原到期时间累加，不立即刷新流量。到原到期时刻才开新周期；购买多个月时每 30 天刷新一次。
- 最终到期时未确认下一次续费，流量继续累计，不自动刷新。到期后确认续费必须手动指定未来到期时间，确认时开启新周期。历史用量及用户订阅扣费保留。
- 在剩余 48、24、12 小时及逾期时生成后台运维预警。“确认已知晓”只确认预警；“确认已续期”才修改到期时间。
- 有效期和容量仅供管理员核对。HQIP 不因服务器到期停止服务器或节点，也不向用户发送提醒。

续期使用服务器版本检查与请求幂等键，网络重试不会重复延期。所有确认保留管理员、确认时间和前后到期日期。

原生小时计量用于处理任意整点周期边界，不与分钟派生小时重复累计；节点离线补报按流量发生时段归属。旧 Agent、长期采样缺失或逾期确认所在的部分小时无法可靠拆分时，显示“用量数据不完整”，不把不确定旧流量算入新周期。完整历史累计继续保留。

## 指标含义

- 月度和累计用量来自设备代理计量账本，不包含内部连通性探测，不等于 VPS 厂商网卡账单。服务器上的其他应用流量不计入。
- 实时代理速率包含连通性探测。上传和下载分别从字节/秒乘 8、除以 1,000,000 转为 Mbps，并各自除以配置容量；不把全双工流量相加作为单向带宽占用。
- 尚未确认停止的已安装节点应持续报告；只有最近 30 秒内且内核健康的报告参与实时汇总。缺失部分节点时显示已知合计和“数据不完整”，不显示确定的带宽占用率；全部缺失显示未知，不表示速率为零。
- CPU、内存、磁盘仅取一份最新有效主机报告，不累计同机多个节点重复报告。无有效报告显示未知。磁盘是 Agent 数据目录所在文件系统，并非所有挂载盘总和。
- “最近报告”是控制端收到报告的时间，不能视作独立的系统资源采样时间。页面请求失败时保留上次数据，并提示过期。

## 历史核对

服务器详情展示最近 24 小时分钟数据和最近 7 天小时数据。切换时间范围会请求相应数据，不只是裁剪当前图表。未收到的历史桶可能是无流量，也可能尚未补报，不能据此断言节点当时在线。

节点贡献表列出各 IP 节点的独立额度和用量；已删除节点单独列为历史贡献。删除节点、设备或 IP 清单不会抹除账本。同 IP 重新部署使用新节点 ID，新旧账本分别累计，补报按原计量映射归属。详细数据沿用现有保留周期，累计用量保存在独立账本。

## 发布与回退

本次增加独立服务器周期与小时统计表，订阅 schema 保持 5。控制服务先兼容新上报，再逐节点升级 Agent；节点核心不需要更新。已有服务器不会因升级而被自动设置日期或清零。

现有 CI 先执行 Linux／Windows 检查，再通过 `scripts/upgrade_domains.py` 备份配套数据库、主密钥及站点配置并发布。发布包同时更新固定校验的 Agent 安装产物，HY2 等其余二进制保持原值。用 `scripts/upgrade_node_agent.py upgrade --node-id ID --artifacts /受校验产物目录` 更新已部署节点：先备份配置与 SQLite 账本，只重启对应 Agent，核对核心运行代次未变。备份目录权限受限，不提交 Git。

上线后检查小时统计能力、心跳、服务器与节点周期用量、历史贡献和预警。新版统计表初始化后，回退程序必须声明支持 `serverBillingVersion: 1`；即使尚未配置周期，旧控制程序也无法接收新增 Agent 报告字段，因此回退会被拒绝。此时应使用兼容周期结构和小时协议的修复版本。Agent 回退仅恢复服务程序路径，不覆盖最新账本或核心配置。任何恢复操作都不得用旧数据库覆盖新产生的用量。
