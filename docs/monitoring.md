# 服务器与节点监控

服务器卡片汇总整台 VPS 的 HQIP 节点，点击任意卡片进入服务器详情。身份验证表示 SSH 主机身份已固定，运行状态取决于节点报告；两者不等同。列表可按名称、SSH 地址或公网 IP 搜索，并筛选异常服务器。

## 容量和流量额度

添加服务器时可填写带宽容量（Mbps）和月流量（GB/TB），也可选择无限。已有服务器通过“编辑名称与额度”修改，无需重新提供 SSH 密码。更换 SSH 管理地址仍需要验证原主机身份。

服务器和节点的额度独立：服务器额度用于整台 VPS 的容量参考，节点额度用于单个 IP 实例。修改一个层级不会修改另一层级，也不会改变设备分配、重启代理、限速或断网。服务器和节点分别在本月用量达到 80% 和 100% 时提醒；修改额度立即按已使用量重新计算，选择无限后隐藏百分比，计量继续。

GB = 1,000,000,000 字节，TB = 1,000,000,000,000 字节。月度统计按北京时间自然月计算上传和下载之和，累计用量不会在月初清零。

## 指标含义

- 月度和累计用量来自设备代理计量账本，不包含内部连通性探测，不等于 VPS 厂商网卡账单。服务器上的其他应用流量不计入。
- 实时代理速率包含连通性探测。上传和下载分别从字节/秒乘 8、除以 1,000,000 转为 Mbps，并各自除以配置容量；不把全双工流量相加作为单向带宽占用。
- 尚未确认停止的已安装节点应持续报告；只有最近 30 秒内且内核健康的报告参与实时汇总。缺失部分节点时显示已知合计和“数据不完整”，不显示确定的带宽占用率；全部缺失显示未知，不表示速率为零。
- CPU、内存、磁盘仅取一份最新有效主机报告，不累计同机多个节点重复报告。无有效报告显示未知。磁盘是 Agent 数据目录所在文件系统，并非所有挂载盘总和。
- “最近报告”是控制端收到报告的时间，不能视作独立的系统资源采样时间。页面请求失败时保留上次数据，并提示过期。

## 历史核对

服务器详情展示最近 24 小时分钟数据和最近 7 天小时数据。切换时间范围会请求相应数据，不只是裁剪当前图表。未收到的历史桶可能是无流量，也可能尚未补报，不能据此断言节点当时在线。

节点贡献表列出各 IP 节点的独立额度和用量；已删除节点单独列为历史贡献。删除节点、设备或 IP 清单不会抹除账本。同 IP 重新部署使用新节点 ID，新旧账本分别累计，补报按原计量映射归属。详细数据沿用现有保留周期，累计用量保存在独立账本。

## 发布与回退

本次监控扩展保留 schema 3，通过服务器 JSON 配置增加可空额度，旧服务器缺省无限，无需升级 Agent 或 Windows 客户端。数据库、主密钥、节点凭据和订阅均保留。

使用 [服务器部署与恢复](server-deployment.md) 中的受校验发布目录，以及 `scripts/upgrade_control.py` 执行冷备份、切换和两路健康检查。备份包含配套数据库、主密钥、服务配置和旧版本路径，权限受限；不得提交到仓库。无需重新运行初次建站或旧本地隧道脚本。

上线后检查服务器与节点用量、历史贡献、Agent 心跳、首页总用量及额度提醒，并确认其他站点的 Nginx 配置未变化。回退时使用本次备份目录；升级后新产生的数据先保留归档，不将旧数据库直接覆盖正在运行的进程。
