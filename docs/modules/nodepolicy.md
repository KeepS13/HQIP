# node-metering / nodepolicy

公共守卫位于 `runtime/nodepolicy`，是无第三方依赖、无 HY2/QUIC 依赖的独立 Go 模块。鉴权与套餐规则仍归 Agent / store 所有。HY2 和 VLESS 是同一业务能力的两个适配器；不复制余额、名额或倍率判断。

公开接口为 `NewAdmission`、`Admission.Open`、`Lease.TCP/UDP`、`Lease.Finish`、只读 `Lease.Snapshot`，以及 `billing` 的固定点类型与运算。准入输入包含随机连接 ID、凭据、可信来源 IP 和快速终止回调；拒绝、非法回执或连接错误均不能启用备用授权。`Snapshot` 只用于原始遥测，不能用于第二次结算。

租约拥有累计有效载荷、协议计费段、速率计划和单调时钟期限。续约与 final 按 `renewMu → mu` 顺序串行；出站终止回调不得回调租约方法。final 幂等，先停止数据，再向 Agent 交付累计报告。Agent 未持久确认的授权预算不能复用。带宽单位为每方向字节/秒，计费单位为百分之一字节，余数、协议倍率和节点额度仍遵守原契约。

VLESS 出站位于 `internal/outbound`：每个共享授权拥有其 TCP/UDP 目标套接字，撤权或上下文取消关闭全部套接字及进行中的拨号。DNS 4 秒、TCP 拨号 10 秒；UDP 目的缓存最多 256 项、60 秒过期。入口仍限制 4096 个连接/授权组。原始遥测不逐包访问 SQLite，按原一秒采样节奏批量落盘，关闭时补采最后快照；未落盘快照保留且受既有 16384 队列容量约束。

Agent 的 `directMu → 租约快照锁 → ledger.mu` 保护采样所有权；不在其锁内执行鉴权或套接字关闭。直接出站的累计基线和流量桶在同一 SQLite 事务更新，与 HY2 使用不同基线键、相同业务统计 ID。Agent 重启仅清理不可能继续增长的旧直连采样基线，保留流量桶、配额及未确认计费账本。正常退出先排空协议会话，随后关闭本地准入 HTTP，保证 final 有机会持久化。

小时覆盖时间表示整节点统计的完整性。已有 HY2 采样时，VLESS 不提前推进该时间，避免掩盖 HY2 崩溃丢失的尾部计数；VLESS 已知流量仍独立落盘并随小时桶上报。尚无 HY2 采样时可由 VLESS 建立覆盖。首次累计样本的时间分布标为不确定，时钟回退保留计数等待重试，超过 24 小时的采样中断只保留准确总量并收窄覆盖，不虚构逐小时明细。

依赖分类：守卫和计费规则为可复用能力；Agent HTTP 为本项目适配器；HY2/Reality 为可替换协议适配器；直接连接器拥有出口绑定、DNS 和网络策略；持久账本和中央订阅事务沿用既有实现。默认网络拒绝列表同时生成受管 HY2 ACL。对 HY2 YAML 的单独人工网络策略调整不再隐式影响 VLESS，节点网络策略应在公共出站配置/实现中统一维护。

验证入口：公共模块的原始并发预算、限速、过期、计费段和截断回执测试；`internal/outbound` 的来源绑定、私网拒绝、撤权和 final 测试；Agent 的配额/名额/代次/遥测回归；真实 sing-box Reality/Vision TCP/XUDP；真实 HY2 进程崩溃重启与双协议倍率热更新。公共契约见 [protocol-policy](../contracts/protocol-policy.md)。

`Admission.Check(ctx, connectionID, password, peerIP)` 只返回计费身份，错误表示身份未确认；它不创建守卫、启动续约或授权目标连接。旧端点、截断响应、缺失身份或意外租约均拒绝；`Open`/续约拒绝身份专用回执。HY2 适配器在内存中保留该 QUIC 的凭据，结束时清除，以便后续每段业务重新核验，不新增凭据落盘。活动引用和正常 final 在适配器内串行，不改变公共守卫锁顺序。

性能边界：每个新 QUIC 增加一次只读身份请求，复用既有订阅权益查询（含该订阅已分配节点），不新增周期扫描。空闲 QUIC 不再每五秒续约或写账本；每段业务增加一次准入与 final，现有网络期限保持不变。子账本达到原 4096 条容量后选择新父账本；旧记录不淘汰，持续高频业务仍受节点账本总容量约束，不以丢失结算换可用性。
