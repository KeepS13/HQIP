# node-metering.protocol-policy

所有者：`runtime/nodepolicy`、Agent 本地业务账本。版本：1。消费者：HY2 服务端、VLESS + Reality 独立出站。

公共守卫负责授权回执校验、120 秒单调时钟租约、5 秒续约、双向独立限速、共享预算、固定点计费段、撤权和幂等 final。Agent 和控制端仍是鉴权、套餐、节点额度、连接名额及累计结算的唯一规则来源；沿用 `node-quota-v1`、`connection-slots-v3` 和 `traffic-billing-v1`，无新业务表。

协议提供可信来源 IP、随机连接 ID、凭据和终止回调。HY2 使用本机认证 HTTP 适配器；VLESS 使用同一入口的本机认证请求，不建立 HY2 客户端或隧道。数据仅在公共守卫许可后通过各协议的出站，TLS、Vision、XUDP 和 QUIC 封装不计入有效载荷。写入失败仍保守计入已预留字节。

VLESS 同凭据同来源 IP 的流共用一个授权，最后一条流结束后保留 5 秒；中央继续跨节点按订阅来源 IP 去重。已释放名额须在线重新申请。撤权、到期、配额耗尽关闭该授权下全部 TCP/UDP；目标连接失败不撤销其他流。final 先持久化再补报，未知预算不能复用。

VLESS 的连接运行代次属于 Agent；HY2 属于其宿主进程。旧账本未带独立代次的子连接仍按 HY2 规则处理，不能把升级前的未确认预算当作零用量。HY2 崩溃、重启、统计接口不可达不使 VLESS 拒绝新授权、失去端点能力或结束已有授权。Agent 重启仍会断开 VLESS。

出站保留节点 IPv4 绑定、DNS 与私网拒绝策略。连接、DNS 和等待速率均可取消且有期限；并发上限沿用入口 4096。公共模块无 HY2/QUIC 依赖。测试覆盖守卫原有规则、双协议共用账本、无 HY2 的真实 Reality TCP/XUDP、HY2 代次变更与撤权。

VLESS TCP 目标只解析一次，最多尝试 16 个已通过私网拒绝策略且去重的 IPv4。解析与连接共用 10 秒预算，最多两个同时拨号；首地址未完成时 250 毫秒启动备用，失败可提前启动。首地址保留剩余总预算，中间备用尝试最多 3 秒，最后候选使用剩余预算。只把一个成功套接字交给业务守卫，取消或迟到的其余套接字必须关闭；不重放应用数据。UDP 继续使用单个目标及原有有界缓存，不发送重复数据报。

发布必须同时构建公共模块消费者；Agent 配置的旧 `reality.backendPort` 只为读取既有配置保留，不再用于拨号。控制端及现有账本契约保持兼容。验证记录另存 `docs/`，不写业务库。

HY2 将 QUIC 身份认证与业务租约分离：只读 `Check` 允许保留空闲传输，目标连接通过 `Open` 才能转发，最后一个目标结束即 final，不为 QUIC 保活续约。计费、撤权、实际业务并发上限保持原规则；同一传输再次使用必须重新申请。UDP 空闲关闭与异常保护期见 [在线计数](online-ips.md)，发布顺序与接口见 [名额契约](connection-slots.md)。
