# node-metering.node-quota

所有者：订阅授权与节点计量。版本：`node-quota-v1`。消费者：支持该能力的 Agent；内核继续消费已有本地子租约。

控制端 desired 的 nodeQuotaVersion=1 表示可接受该契约。Agent 在协议父授权请求中附带 quotaCapability=node-quota-v1；当前新准入只接受带可信 clientIP 的计费与节点额度请求，旧授权只保留结算。新父授权通过 nodeQuota 快照标识，同节点同订阅的所有协议与父授权共享一份额度。

快照使用 1/100 计费字节，包含单调 revision、总额度 quotaUnits（null 表示不限量）、网站已汇总 usedUnits、当前节点已被网站确认的 nodeUsedUnits，以及旧格式授权仍占用的 legacyReservedUnits。中央在订阅锁与同一数据库事务内结算累计报告、更新确认水位并生成快照；同版本重放不会增加用量。

续费能力增加可选 `periodId`，所有用量、水位和未归还预算只在同一周期内相抵；revision 仍在整份订阅内单调递增。旧快照缺少 periodId 时归入初始周期（周期 ID 等于订阅 ID），已有节点累计水位继续使用。新周期使用独立节点水位和计费余数。旧期迟到报告只更新旧期账本，返回的快照保持旧期身份，不能给旧子连接贴上新期标识。节点重启后仍按持久化的周期筛选授权与未结算子预算。

节点可用额度 = 总额度 - 网站已用 - 旧预留 -（节点累计新用量 - 网站确认的该节点用量）- 本节点已交给内核而尚未归还的预算。所有协议共享此计算，使用 SQLite 持久化后才能发放子租约；丢失 final 的预算不能重用。节点本地实际计费应用当前已确认的协议倍率，固定点整数计算，不因重连或重启重置。

网站断开时沿用最新快照与策略，直到余额耗尽、订阅到期或已知登录会话到期。节点不能离线获得从未授权过的订阅。用户明确允许不同节点各自依据最后同步余额继续服务；因此断网期间多个节点合计可能超过套餐。恢复后先接受全部真实用量，再按总额停止授权，超额补报不得被丢弃或回滚。恢复后尚在内核内的短租约遵循原 120 秒上限及 5 秒续约。

已续费订阅的父授权截止不得超过本期结束；付款延长总到期不会延长旧期父授权。下一期必须在线取得新授权，失联时不能预支未来额度。上线续费须同步升级控制端与 Agent；旧 Agent 不理解周期隔离，不能作为续费上线的验收对象。内核继续使用已有子租约截止字段。

管理员调整有效期后，节点额度父授权在下一份有效报告中同步最新本期终点及登录会话截止，包括空闲报告、释放和重新申请名额。此更新不会重新占用已释放名额，不改变周期身份或累计用量，也不会恢复已经到期或撤销的授权。节点接收截止缩短和迟到回执后，再按当前时间及名额状态独立裁决是否可发放子租约。

新授权不占用中央流量预留、也不新增应急流量；连接名额与流量账本按 [connection-slots-v3](connection-slots.md) 独立管理，释放时同步清退旧带宽份额，重新申请后重新预留。旧父授权仅在所有子 final 已确认后自动最终结算。对于已确认结束但缺少 final 的旧子连接，新 Agent 先持久化禁止复用，再通过 retainedNormalUnits 归还从未下发的父预算；每个未知子连接仍保留完整已委托预算，不伪造最终用量。网站在同一事务中结算已有用量、缩减未委托预留、撤销并到期该父授权的连接名额。未知余额直到真实 final 到达才释放。待确认报告必须原样重放，不能插入新字段改变旧版本。

鉴权沿用节点 Bearer token、凭据绑定与订阅权限。非法计数/版本冲突返回 409；撤销/到期/额度不足返回 403；暂时不可达保留本地账本和原样待补报快照。节点丢失业务账本不能用网站确认水位推测未报用量。

倍率设置及数值仅在管理界面展示。用户界面显示套餐总额、已用和余额，不展示倍率设置；现有桌面端内部仍消费已确认计费策略来估算统计，不将策略数值显示给用户。
