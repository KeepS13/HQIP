# subscription-admission.online-ips

所有者：store 订阅事务、Agent 本地账本、HY2/Reality 入口。版本：connection-slots-v3。保留原契约 ID 与文件路径。

每份订阅的 maxConnections / occupied 表示同时在线上限 / 已占名额，字段名保持 API 兼容。HY2 每个存在 TCP 目标连接或 UDP 会话的客户端实例占一个名额；VLESS 按代理入口实际观察到的来源 IP 去重，同一订阅内跨节点、跨连接凭据共享一个 IP 名额。两者相加受同一个上限约束。nodesPerSubscription 只控制从套餐节点池获配几个节点，与在线上限独立。

同一 WiFi 下两个 HY2 实例加一个 VLESS 来源占三个名额；三个 VLESS 客户端共用一个出口 IP 只占一个名额。同一台设备同时建立多个 HY2 会话也分别计数，这不是硬件设备识别。VLESS 忽略源端口；IPv4-mapped IPv6 规范化为 IPv4，其余 IPv6 按完整地址计数，换网或同时使用 IPv4/IPv6 可能占用多个 IP。不同订阅独立计数。

HY2 内核从 QUIC 连接取得实例身份与 clientIP；Reality 从入站 socket 取得原始 IP 并放入节点签名的内部凭据，不能使用回环转发地址、订阅下载地址或第三方客户端自报字段。控制端只信任已认证节点提交的规范化 IP，缺失或非法 IP 的新准入被拒绝。

复用 portal_leases.client_ip、现有订阅事务及 Agent 账本，协议读取现有计费账本的不可变 grant.protocol；v3 不新增表或数据库列。同一连接重放不可改变 IP 或协议。每个 HY2 父账本同一时刻至多承载一个活跃子连接。准入、续约、重新申请、套餐降额、带宽重分配和页面占用共用计数规则，检查与写入在现有订阅事务内串行完成。每条连接保留独立计费记录，共享套餐带宽及流量，不因 VLESS 去重而获得额外额度。

HY2 最后一个业务目标结束后提交 final 并释放自己的名额，保留的 QUIC 及其保活不占名额；再次使用必须重新准入。VLESS 的同 IP 最后一条有效占用结束后释放该 IP 名额。显式撤销但尚未确认结束的连接继续占用。异常结束沿用内核 120 秒有效期及节点 5 秒保护期。控制端失联不能证明连接结束：保留已经批准的占用，只允许仍持有名额的账本在原节点续用或重连，不离线批准新增名额。连接名额释放不删除未知用量或待确认累计报告。

迁移幂等并保留原账本：首次启用 IP 契约时增量增加 client_ip；从 v2 升级 v3 只推进计数版本。历史行缺少可信协议或 IP 时按各自许可 ID 保守计数，禁止把空 IP 合并。旧 IP 规则下已超出 v3 上限的 HY2 实例，在后续续约或报告时按建立顺序保留允许数量，其余撤销且接受真实最终用量。新许可及发布包返回 connectionSlotsVersion=3，回退检查拒绝不理解新计数规则的旧节点或控制端。旧无 IP 许可只保留结算用途。

验证覆盖：同 IP 多个 HY2 实例、VLESS 跨节点和凭据去重、两协议合计上限、并发抢最后名额、逐个断开与最后一条结束、满额重放、释放后重新申请、IPv4-mapped IPv6、伪造 Reality 来源、降额与限速、旧数据迁移及迟到 final。

HY2 握手使用只读身份检查，不申请名额、带宽或流量。目标拨号前通过原事务申请，同一 QUIC 的并发目标共用一次活动授权；拨号失败归还引用，最后一个目标关闭后停止续约并提交真实累计 final。正常释放不强行关闭 QUIC，以免截断已写入传输缓冲区的响应。测速正在传输时仍受限制，结束后不持续占位；不按测速网址或流量阈值豁免准入。

业务 TCP 长连接（HTTP keep-alive/WebSocket 等）仍视为在线，不能仅凭一段时间无流量回收。关闭系统代理开关不等于关闭既有目标连接。HY2 UDP 没有显式会话关闭信号，沿用 60 秒默认空闲期限及 1 秒扫描周期；QUIC 结束会关闭全部目标。缺失 final 沿用上述保护期，不猜测未知流量。
