# subscription-admission.import-links

Owner: subscription-admission（internal/store、internal/control）

Version: 1（兼容现有单份导入链接）

Consumers: user-web、第三方 Clash/Mihomo、V2Ray、sing-box 客户端。

人工开通扩展：`pending` 订阅同样允许创建/复制/轮换链接并进入合并集合，见 [activation v1](../subscription-activation.md)。尚未开通的单份或仅含待开通成员的合并链接返回 200 空节点配置；Clash/sing-box 拒绝转发，V2Ray 为零条 URI。它不授予连接权限；首次分配节点并开通后刷新原链接即可。以下“有效订阅集合”在链接管理语境包含待开通成员；全部失效 403、没有合格自动节点 503 不适用于仅待开通的集合。

## 请求与响应

- `GET /api/v1/user/subscriptions/{id}/import-link` 读取单份链接。
- `POST /api/v1/user/subscriptions/{id}/import-link` 幂等准备单份链接；`/rotate` 轮换；`/revoke` 撤销。
- 将以上路径的 `/subscriptions/{id}` 移除，操作范围变为当前认证用户的全部订阅。
- 浏览器接口要求用户会话；所有 POST 要求同源与 CSRF。返回 `{url: string}`，不信任调用者传入的用户 ID。
- GET 不创建凭据；没有链接、没有有效订阅或合并成员中尚有缺失链接时返回空字符串，不返回部分集合。
- 自动准备只发生在进入复制页面时。平时刷新为 GET；撤销后再次点击复制可以显式准备新链接。

## 合并语义与兼容

合并链接是复制时有效订阅集合的快照，用已有的单份令牌组成 `/usub/{token}` 路径，不引入额外账户授权或数据库表。后续购买须重新复制。单份链接保持原样。有效订阅按 ID 稳定排序；同一集合反复准备返回同一链接，不断开现有连接。

配置导出仍使用 `format=clash|v2ray|singbox` 和 `download=1`。合并中每份节点使用该份自己的凭据，并为节点标识和名称添加订阅标识，避免同名模板、同一服务器互相覆盖；计费、限速和在线名额仍按订阅实例隔离。失效成员不输出节点，全部失效返回 403；没有合格自动节点时返回 503，部分成员暂不可连接时仍可导出其他有效成员。

## 失效、事务与错误

轮换或撤销在一个事务中更新入口令牌、删除对应第三方凭据并撤销现有租约。写事务先锁用户，再更新订阅、凭据和租约；数据库冲突按既有重试策略处理。任一失败整体回滚，不产生部分轮换。

“全部”轮换／撤销覆盖该用户的全部第三方凭据和旧入口（包含已经失效的订阅）；新链接仅包含当前有效订阅。单份操作只处理该份的凭据。旧合并链接只要有一个成员令牌被轮换、撤销或移除，整个旧链接返回 404，绝不交付新凭据或悄悄退回部分集合。

旧节点凭据不能建立新连接；正在转发的租约在节点下一次同步时撤权，可能存在网络同步延迟。待结算预留和账本保留到最终结算，原生 HQIP 会话及凭据不受影响。导出响应写出前再次验证全部令牌，避免在途旧 URL 获取轮换后的新凭据。

跨账户拼接、重复令牌、格式错误和撤销链接返回 404；未登录为 401，CSRF 失败为 403，外部用户的单份 ID 为 404。失效订阅创建或轮换为 403，仍可撤销。数据库错误不当作空订阅或部分成功。

## 规则模式（2026-11-23 修正）

Clash、sing-box 的完整配置及 HQIP 原生规则模式统一执行大陆域名和 IPv4/IPv6 直连，优先于保存的旧服务分组，其余自定义规则保持顺序。配置生成时组合内置快照，因此已有 LAN-only 包也生效；导出不写回规则历史、哈希或凭据。Clash 内联 CN 地址，不依赖客户端 Geo 数据库，并提供大陆 DNS 策略和保留目标地址的 HTTP/TLS 域名嗅探。sing-box 使用本地 DNS 做大陆域名及 IP 分类。

`format=v2ray` 保持 Base64 节点 URI 列表，不携带路由，不能自动修改 v2rayN、v2rayNG 或 Shadowrocket 的配置。它们需要在客户端选择大陆直连规则；全局模式或本地覆写不受服务器配置保证。真实验证版本、数据更新和其他边界见 [大陆分流](../mainland-routing.md)。

## 导出性能边界

最多合并 100 份有效订阅，令牌段最多 4399 字节；超过上限拒绝，不截断。每次导出最多解析 100 份并复用现有配置构建器，节点额度上限沿用每份最多 1000。链接状态每 30 秒及页面重新可见时读取，同一页面不会重叠轮询；读取不构建节点配置、不发放节点凭据。账户用量沿用自己的刷新周期，不存在独立后台任务或新增数据库迁移。
