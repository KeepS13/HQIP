# client-runtime.commands / client-runtime.updates / client-runtime.changes

Owner: client-presentation（internal/client、internal/clientbridge、godot-client）
Version: 1；远程账户契约沿用 `/api/v3/client/*`。
Consumers: Godot Windows、Android；原 Wails Windows 继续消费相同控制器。

## 边界与所有权

Godot 只接收不含令牌、密码和节点凭据的 `View`，通过显式命令选择订阅、节点、连接、断开和登录。Go 控制器拥有账户令牌、订阅选择、连接状态及持久化。Windows 凭据由 DPAPI 保护；Android 由 Keystore 保护。不会复制计费、名额或授权规则到界面。

Windows 界面与运行时使用继承的标准输入输出管道，逐行 JSON `{id,method,params}` / `{id,result,error}`；不开放无认证 TCP 控制端口。状态查询不阻塞连接命令；断开和取消登录必须能抢占等待。管道关闭时关闭运行时并恢复本应用拥有的网络状态。

状态除原 `View` 外增加 `version`、`platform`、`updates` 和 `autoStart`。Go 的 nil 列表可编码为 `null`：界面只将容器字段规范为空列表/对象，保留流量上限、延迟等业务字段的 null 含义。状态每秒读取一次且最多一个待处理请求；节点列表仅在相关数据或搜索条件改变时重建。`delay` 调用既有代理延迟检测，`autoStart` 仅控制本用户独立的 `HQIP Godot` 启动项。

所有连接状态下，`node` / `subscription` 都先校验登录时已导入的套餐与全部可选节点目录、加密保存本机偏好，立即返回选择结果。未连接时不请求账户或操作内核；已有连接意图时，后台自动停止旧连接并连接新选择。保存失败不发布新选择，也不停止原连接。本机草稿绑定服务地址和账户 ID，刷新与重启保留选择。`View.desired*`、`subscription`、`nodes` 与 `defaultNodeId` 展示这份选择，授权 Profile 与实际连接 ID 保持独立。连接详情按 `actualSubscriptionId` / `actualNodeId` 展示实际使用目标；不能在新连接成功前把待用节点标成已连接。导入目录不提前为每个节点申请连接凭据或名额。

首次使用需显式 `connect`；已连接、连接中和恢复中接受新选择后，自动消费最新草稿。同套餐复用已验证授权与规则，跨套餐执行既有 revision 约束的释放、授权选择与目标校验，再连接准确节点。同套餐不重复导入目录、提交套餐选择或下载规则，不变的已验证规则摘要可复用缓存。重复选择同一目标、重复 `connect` 均幂等。

选择命令不等待 `routeMu` 或网络；保存成功后立即递增连接/选择代次，取消旧连接、恢复和延迟任务，后台按 `routeMu → mu` 准备最新目标，再交给既有 `applyMu` 串行的停止/释放/连接流程。较晚完成的授权响应不得覆盖更新的选择。被取消的授权请求可能已在服务端提交，内存按 API 会话记录这一不确定性；下一次连接必须先重新核实授权，即使又选回原节点，也不能复用旧 revision。手动断开先撤销连接意图并取消排队切换，旧任务不得重新连接。失效套餐、无效节点、连接失败不得回退其他目标。断开完成本机停止后立即返回，账户上报由受控工作任务完成，退出会取消并等待任务结束。

`node` / `subscription` 成功响应携带无敏感字段的 `View`，Godot 合并展示，无需额外等待一次状态查询；旧界面忽略结果并继续轮询也兼容。`state` 和选择回执均附加 `snapshotSequence`，在同一 Bridge 生命周期内按原生 View 的采集顺序单调递增。短锁只覆盖采集和编号，不包围命令或网络；请求 ID 和返回顺序不能替代采集顺序。Godot 丢弃不更新的快照，迟到的选择回执仍结束对应等待、继续保存最新选择，但不覆盖较新状态；因此断开后不会被旧回执恢复成“已连接／检测中”。不补发额外查询。旧运行时无编号的完整快照保留请求屏障兼容；选择成功却只返回布尔值时明确提示运行时不匹配。`selectionPending` 表示后台切换准备或授权阶段，不阻止继续选择；连接卡片显示切换状态，选择器仍立即响应。账户刷新、节点测速、连接、更新各用自己的等待状态。

所有连接状态下，Godot 在点击处理内从已同步目录一次性投影目标节点、套餐小字和套餐摘要，不等待磁盘回执。原生快照与展示草稿分开：本地保存只有一个在途命令，连续点击覆盖待保存目标，旧回执不得覆盖最后一次点击。当前保存失败回退至最后一次确认的整组选项；已被新选择替代的失败不覆盖新意图。确认前 Connect 与当前节点测速不可提交，断开仍可立即操作。节点弹窗先关闭再通知 shell，避免关闭前无效重建。重复选择已确认目标不发送命令。

隐藏页面不参与每秒渲染，打开时应用最新快照；套餐用量原位更新，节点列表重建只依赖目录、套餐名称/有效性、测速、选择和搜索条件。按钮的 normal/hover/pressed/hover_pressed/disabled/focus 保持同一内边距，状态只改变颜色/边框，不能影响布局高度。

“我的订阅”是纯信息页：按内容宽度与套餐数量显示一至三列卡片，不显示本机选择、不发送 `subscription` 或 `node`。所有选择统一经仪表盘节点弹窗完成；卡片只在订阅 ID/顺序改变时重建，计量、名称、状态和有效期原位更新。底部 `shop` 命令由原生端从当前账户服务地址生成网站 `/catalog` 地址，不接受界面指定 URL，不携带令牌；打开网页不触发额外状态查询。

仪表盘 `testNode {subscriptionId,nodeId}` 只探测显示的一个节点。原生端在锁内确认它仍是本机当前选择且目录授权有效，拒绝过时请求，不自动选择其他节点。`nodeTests.nodeId` 非空表示单节点任务，配合 `subscriptionId` 归属当前按钮；空值保留 `testNodes` 的全量/旧客户端语义。测速复用握手探测，不申请连接名额、不操作内核、不提交订阅切换；已有其他节点结果原位保留。相同目标重复请求幂等；显式切换测速范围取消旧任务，旧工作线程不能覆盖新结果。`cancelNodeTest {subscriptionId,nodeId}` 仅取消匹配的单节点任务；`cancelTest` 仍取消当前任意测速任务。更换本机选择不重定向在途探测，撤销授权、端点变化、退出与关闭会取消。节点列表握手测速仅接受手动命令；登录、同步、刷新和空闲选择不自动测速。

每次实际连接成功或同节点恢复成功后，自动执行一次当前连接的代理延迟检测，结果存于 `metrics.delayMs/delayAt`；`delayPending` 表示本次检测中。仅测实际连接，不遍历目录；预算 5 秒，不周期重测、不失败重试，失败显示空值且不停止 VPN。手动 `delay` 可再次检测，与自动任务共用单在途约束。切换、断开、恢复开始时取消旧任务并清空结果，结果提交同时验证连接代次/状态。Godot 仅在所选订阅和节点都与实际连接匹配时显示该延迟，不把旧节点结果投射到新选择；连接详情始终描述实际目标。

Android 原生初始化在工作线程执行，不阻塞 Godot 首帧。通过进程内 JNI 调用相同命令分发器，VPN 服务拥有 TUN 文件描述符和前台通知，界面关闭不等于断开。用户撤销 VPN 权限时必须停止连接。系统授权和安装确认仍由操作系统呈现。Android 嵌入 TUN 使用 gvisor 全用户态 TCP/UDP 栈与 1500 字节 MTU，避免依赖桌面 kernel TCP 返回路由。节点测速与账户解析共用物理网络 DNS，TCP/UDP socket 都必须 protect 并绑定非 VPN Network。

重复 `connect` 在连接意图已开启时幂等，不取消正在建立或恢复的连接；重复设置同一 mode/TUN 也不生成新的连接代次。真实模式改变先保存偏好，保存失败保持原模式、连接代次和恢复权限。持久化成功后才取消旧代次并重建；不能因为用户重复点击而释放健康连接的名额。

Windows TUN 的管理进程绕过规则包含 `hqip-runtime.exe`，顺序在授权暂停规则之前；暂停清理保留该进程的账户和更新连接，普通业务流量仍受暂停规则约束。规则与全局模式都必须保留此边界。

原生规则模式的路由 `resolve` 遵循 DNS 规则，不强制指定本地 DNS。已知大陆/控制端/节点域名使用本地解析，未匹配域名默认经节点使用远程 DoH，再进行大陆 IP 判断，防止污染答案误命中大陆直连。解析结果仍属于大陆的未收录域名可走直连；未经本地解析的域名可能使用不同 CDN。隔离测试不替代真实大陆网络验收。

Android 网络通知按实际选中的非 VPN 网络指纹去重：network handle、接口名称/索引、MTU、地址集合和有序 DNS。无关接口事件、重复通知及地址枚举顺序改变不能重置 socket；实际断网、网络切换及恢复会重置。无效快照不等于断网。指纹比较及回调在同一互斥区串行，防止旧通知覆盖新网络。Android 返回键先关闭节点弹窗/抽屉，在根页面仅将 Activity 放入后台，VPN 生命周期仍由前台服务拥有。

## 直连、重试和兼容

`client-runtime.changes v1`：Profile 可选字段 `changeToken` 宣告增量通知能力。登录完成一次全量目录/规则导入后，Run 复用该结果；恢复持久会话先同步一次。支持通知的服务端通过已认证 `GET /api/v3/client/changes` 维持一条 NDJSON 连接，每 15 秒读取业务版本并发送 `{changeToken}`。标识覆盖账户状态、订阅 revision/期限/周期、节点配置与规则版本，排除流量累计、在线人数、节点心跳和本机选择。网站相关业务修改被观察到后触发一次 Profile 同步，规则摘要不变时复用缓存。使用量展示保留最后同步值，可手动刷新；在线授权和计费检查仍由连接生命周期处理。

同标识心跳只更新内存中的在线联系时间，不重新导入、不落盘、不上报、不改变 `LastSync` 或离线授权期限。已使用的离线许可临近到期（两分钟内）时允许必要的授权刷新，频率不超过每分钟一次；期限仅取真实 Profile 授权，心跳不能自行延期。并发刷新共用一次完成结果；完全相同且已成功上报的连接状态不重复上报。空闲客户端不请求连接名额、计费或转发验证接口。

通知连接在注销/关闭时取消；客户端单行上限 4 KiB，45 秒未收到通知则取消读取，重连按 1–60 秒指数退避，仅稳定存活 30 秒后重置退避。服务端每个原生会话最多一条通知连接，独立容量上限 2048，每次写入预算 30 秒；每轮重新校验令牌和会话，`{reauth:true}` 要求客户端轮换令牌，明确鉴权失败沿用退出流程。此容量上限是资源边界，不代表已通过相同并发规模的压测。

旧服务端未提供标识，或通知路由返回 404/501、非 NDJSON 时，客户端停止尝试可选通知接口；空闲时不轮询账户，已连接时保留每 60 秒授权刷新，手动 Refresh 仍可用。要获得网站变更通知，必须同时更新控制端；仅安装客户端不会让旧服务端具备推送能力。

账户请求、规则和安装包下载必须禁用 HTTP 代理。Windows HTTPS 数据连接绑定物理默认出口；Android 使用系统非 VPN 网络和 socket protect。证书检查不可关闭，授权不随重定向传给其他来源。

账户请求总预算 25 秒。仅 GET 允许传输失败后立即重试一次；刷新保留已持久化 requestId，在下一轮同步或重启后恢复。一次性授权码交换、订阅修改、注销与连接释放不盲目重放。取消和证书错误不重试。网络异常不等于会话失效，只有服务端确定的账户鉴权失败走现有退出流程。

客户端显示版本不作为账户接口准入条件；兼容字段采用增加方式。未知可选字段忽略；未知协议不得伪装成 HY2。最低版本只用于确实不能兼容的安全/协议升级，不能因为发布普通新版就强制断开旧版。早于 v3 的单套餐客户端不能假称兼容多订阅模型；已下线域名的旧安装需要保留旧域名服务或至少一次迁移安装。

## 更新行为

登录后自动获取账户、节点和规则；应用启动后立即在后台检查公开签名安装包，无需登录，不发送账户凭据，安装失败保留当前版本。来源取本机配置的服务地址（首次安装为官方地址），不由登录状态或订阅有效性决定。下载来源必须是配置的 HTTPS 服务，摘要、尺寸、平台及版本均校验，拒绝跳转、路径穿越及降级。不下载执行 GDScript、DLL 或任意脚本作为跨平台“资源更新”。

Windows 首次安装交付单个 EXE 安装包，默认写入当前用户 `%LOCALAPPDATA%/Programs/HQIP`，不要求安装提权；运行时的 TUN 授权独立处理。快捷方式指向固定 `HQIP.exe`，安装包包含首次离线启动所需完整文件。更新协议内部继续使用完整 ZIP，无需用户下载或解压。覆盖安装保留更新指针及账户目录；卸载清除应用版本目录，仅移除指向本次安装的自启项，保留 `%LOCALAPPDATA%/HQIP/Godot` 的账户设置。安装与卸载必须等待客户端正常退出，不强杀代理进程。

Windows 在退出并停止代理后切换完整版本目录，下次启动验证失败可回到原目录。Android 按运行架构分别匹配 `android-arm64` 与 `android-amd64`，拒绝交叉架构包。使用相同签名的 APK，下载后由系统确认安装；不得承诺普通应用静默安装。iOS 安装包和执行代码更新保留 App Store/TestFlight 渠道，不能用 PCK 绕开发布审核。

元数据使用固定 Ed25519 公钥验签，包使用 SHA-256 校验。`sequence` 单调递增，是更新顺序及防回放的唯一依据；展示版本可重新编号，不能复用同一序号发布不同内容。签名高水位保存到库外文件，重启或下载失败不允许退到较旧发布。每平台保留最近两个发布记录供下载中的客户端完成；更旧的下载返回 404，当前客户端可继续使用并在之后检查最新包。发布工具在清单原子写入后验证保留包并回收未引用包；只删除通过摘要检查的约定单文件目录，异常清单、缺包或内容损坏时停止，未知内容和链接保持原样。此操作要求独占发布者，记录保存在库外，不能与另一轮发布并行。

清单最多 64 KiB、16 条记录，包最多 500 MiB；清单超时 15 秒、下载超时 15 分钟。启动后首次检查，此后每六小时检查；来源变化至多一分钟内重新检查，可手动触发但同一实例只有一个下载任务。Windows 仅接受约定的八个平铺文件，完整暂存后原子写入 pending 指针；稳定启动器校验指针签名，并在 30 秒内未获得界面首个运行时状态或新界面异常退出时回退。此就绪标记不代表真实账户/VPN 已通过验收。

大陆可达性属于部署验收：禁止以“Proxy=nil”或本机美国出口测试通过代替大陆运营商网络验证。用户已指定继续使用现有配置，更新沿用账户服务 HTTPS 来源及现有 Cloudflare 转发，不另设域名。客户端禁代理不等于已经验证大陆链路可用；更新服务不可要求 VPN 已连接。
# 安装包发布接口（2026-11-24）

`GET /api/v1/user/installers` 独立于旧 Wails 版本查询，返回 `releases` 数组，每项包含 `platform`、`name`、`filename`、`version`、`sequence`、`sha256`、`size`（字节）和 HTTPS `url`。支持 `windows-amd64` EXE、`android-arm64` APK、`android-amd64` APK。未发布时数组为空；清单损坏返回 503；未知内容哈希返回 404。下载端点支持 Range，只有校验成功的内容哈希路径设置长期缓存。

安装包和自动更新包从相同干净提交构建。发布工具拒绝版本、序列或平台缺失/混用。签名身份持续复用；PR 测试身份不参与正式渠道。详见 [CI 与部署](../deployment/client-release-ci.md)。
